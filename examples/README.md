# examples 示例文件

| [test.txt](test.txt) | .txt | 纯文本文件 | [txt 教程](../docs/01-日常办公文档类/txt.md) |
| [test.md](test.md) | .md | Markdown 文档 | [md 教程](../docs/01-日常办公文档类/md.md) |

## 🚀 怎么用

1. 点击上方文件链接，进入文件页面
2. 点击「Download」或「Raw」下载文件
3. 按照对应教程的步骤，亲手打开、运行、测试

## 💡 小提示

- 所有示例文件都是安全的，可以放心下载
- test.py 运行后会生成一个 test_output.txt 文件，可以删除
- test.zip 压缩包里包含了本目录下的所有文本类示例文件
