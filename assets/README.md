# assets 资源目录

本目录用于存放项目所需的配图、示意图、截图等资源文件。

## 目录结构

```
assets/
├── images/       # 通用图片资源
├── screenshots/  # 软件截图、操作示意图
└── diagrams/     # 架构图、原理图
```

## 说明

- 项目初期暂未放置图片资源
- 后续更新会逐步补充各软件操作截图、文件格式原理图等
- 欢迎贡献高质量的示意图和截图（需确保版权合规）

## 图片规范

- 格式：优先使用 WebP，其次 PNG
- 截图宽度：建议 800-1200px
- 文件名：使用小写英文，连字符分隔，如 `windows-show-extension.webp`
- 大小：单张图片尽量控制在 200KB 以内
