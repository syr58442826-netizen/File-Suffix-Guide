# 小众文档与电子书

收录日常使用频率较低、但在特定领域非常重要的文档与电子书格式。这些格式往往有不可替代的专业用途，比如学术排版、扫描存档、电子书阅读、苹果生态办公等。

## 分类简介

本分类收录了在专业领域和特定生态中使用的小众文档与电子书格式，包括：

- **扫描存档类**：DjVu（高压缩扫描文档）
- **开放标准文档**：ODT（OpenDocument 文本）、RTF（富文本格式）
- **学术排版类**：TEX（LaTeX 排版源文件）
- **苹果生态办公**：Pages、Numbers、Keynote
- **电子书格式**：AZW3（Amazon Kindle 电子书）

## 使用建议

- **学术写作/论文排版**：推荐使用 TEX（LaTeX），公式和参考文献处理是强项
- **图书扫描数字化**：DjVu 压缩率极高，是扫描存档的首选
- **跨平台文档交换**：RTF 兼容性最好，几乎所有文字软件都能打开
- **苹果生态办公**：Pages、Numbers、Keynote 在 Mac/iOS 上体验最佳
- **Kindle 阅读**：AZW3 支持丰富排版，是 Kindle 体验最好的格式
- **追求开放标准**：ODT 是摆脱厂商锁定的开放文档格式
