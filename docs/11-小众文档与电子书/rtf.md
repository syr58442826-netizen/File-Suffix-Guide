# .rtf 文件后缀详解

## 1. 文件定义 & 用途

RTF 是 **富文本格式**（Rich Text Format）的缩写，由微软在 1987 年推出。它是一种"带排版的纯文本"——既能像 Word 一样有粗体、颜色、表格等样式，又能像 TXT 一样被几乎所有软件打开。它是跨平台文档交换的"老牌通用语言"。

- **全称**：Rich Text Format
- **类型**：富文本文档（带简单排版）
- **开发者**：Microsoft（1987 年）
- **特点**：纯文本编码（可记事本打开看到源码）、跨平台兼容性极强、不支持宏（天然防病毒）
- **对比 DOCX**：排版能力弱一些，但兼容性强得多，几十年的老软件都能打开

RTF 的聪明之处在于：它用纯文本符号来描述格式（类似 HTML），所以任何能读文本的程序都能解析它，不依赖特定软件。这也是它成为"文档搬运工"的关键。

## 2. 适用场景

- **跨平台文档交换**：Windows、Mac、Linux 之间传文档不丢格式
- **老软件兼容**：需要被 10 年前的软件打开时
- **简历投递**：怕对方没装 Word，用 RTF 最保险
- **数据库/系统存储**：存带简单排版的内容（比纯文本好看，比 docx 轻）
- **防病毒场景**：RTF 不支持宏病毒，比 doc 更安全

## 3. 推荐打开软件

| 平台 | 免费软件 | 专业软件 |
|------|----------|----------|
| Windows | 写字板（系统自带）、WordPad、LibreOffice Writer、WPS Office | Microsoft Word |
| Mac | 文本编辑（TextEdit，系统自带）、LibreOffice Writer | Microsoft Word for Mac、Pages |
| Linux | LibreOffice Writer、AbiWord、Calligra Words | - |

**新手推荐**：
- Windows 用户：**写字板**（系统自带，无需安装）双击即可打开
- 跨平台首选：**LibreOffice Writer**，格式还原完整
- Mac 用户：系统自带的**文本编辑**就能打开编辑

## 4. 如何编辑、如何导出

### 如何编辑
RTF 编辑方式和 Word 几乎一样：

1. **写字板/文本编辑**：系统自带，支持字体、颜色、对齐等基础排版
2. **Word/LibreOffice**：完整功能编辑，支持表格、图片
3. **记事本**：可以打开 RTF 源码（看到一堆控制符号），但不建议这样编辑

### 如何导出/转换
- **Word/Writer 另存为**：文件 → 另存为 → 选择"RTF 富文本格式"
- **转成 DOCX**：用 Word/LibreOffice 打开后另存为 docx
- **转成 PDF**：Word 中"另存为 PDF"，或 LibreOffice"导出为 PDF"
- **转成 TXT**：另存为纯文本（会丢失所有排版）
- **批量转换**：LibreOffice 命令行 `soffice --convert-to rtf *.docx`

## 5. 常见报错与解决

### 问题1：RTF 文件用记事本打开全是乱码符号
**原因**：RTF 是带格式控制符的文本，记事本会显示原始控制代码（如 `{\rtf1\ansi...}`），这不是乱码而是 RTF 的本来面目。

**解决方法**：
1. 这不是损坏，改用**写字板**（Windows）或**文本编辑**（Mac）打开就能正常显示
2. 用 Word 或 LibreOffice Writer 打开，效果更好
3. 右键文件 → 打开方式 → 选择写字板或 Word，并设为默认

### 问题2：RTF 文件体积很大，打开很卡
**原因**：RTF 用纯文本描述格式，图片会被转成超长的十六进制文本，导致体积膨胀（一张图能让 RTF 暴涨几 MB）。

**解决方法**：
1. 尽量少在 RTF 中插入大图片，或压缩图片后再插入
2. 如果主要传文字，改存为 DOCX（图片压缩更高效）
3. 用 LibreOffice 打开后"另存为 → RTF"重新保存，有时能精简冗余代码
4. 不需要排版的话，直接转成 TXT 最省空间

### 问题3：RTF 里的特殊符号或公式显示不正常
**原因**：RTF 对复杂公式、特殊 Unicode 字符的支持有限，不同软件渲染可能有差异。

**解决方法**：
1. 换用 Microsoft Word 打开（对 RTF 兼容性最好）
2. 公式类内容建议改用 DOCX 或直接生成 PDF
3. 特殊符号尽量用常见 Unicode 字符，避免生僻字体符号
4. 如果是发给对方，转成 PDF 能保证显示一致

## 💡 小知识

RTF 已经快 40 岁了，却依然活跃。在云文档普及前，RTF 是"文档界的通用语"——因为它纯文本编码，连 1990 年代的古老软件都能打开。微软自己都惊叹于它的长寿：从 Windows 3.1 的写字板到今天的 Office 365，RTF 一直是被支持的格式。不过随着 docx（也是基于 XML 文本的开放格式）崛起，RTF 的"跨平台优势"不再独特，微软也在 2008 年停止了 RTF 规范的更新。但由于它在旧系统和嵌入式设备上的超强兼容性，至今仍是简历投递、老旧系统对接的"保险格式"。
