# 编程源代码文件

本分类收录了编程开发中常见的源代码和配置文件后缀。

> 源代码文件本质上都是纯文本文件，可以用任意文本编辑器打开查看。要运行它们需要对应的编程语言环境。

## 后缀列表

### 编程语言

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.py](./py.md) | Python 源代码 | 最流行的脚本语言之一，简单易学 |
| [.c](./c.md) | C 语言源代码 | 经典的系统级编程语言 |
| [.cpp](./cpp.md) | C++ 源代码 | C 语言的扩展，支持面向对象 |
| [.h](./h.md) | C/C++ 头文件 | 声明函数和变量的头文件 |
| [.java](./java.md) | Java 源代码 | 跨平台的面向对象编程语言 |
| [.class](./class.md) | Java 字节码 | Java 编译后的字节码文件 |
| [.js](./js.md) | JavaScript 源代码 | 网页前端和 Node.js 开发语言 |

### 网页前端

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.html](./html.md) | HTML 网页文件 | 网页的骨架和结构 |
| [.css](./css.md) | CSS 样式表 | 网页的外观和样式 |

### 数据与配置

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.json](./json.md) | JSON 数据文件 | 轻量级数据交换格式 |
| [.xml](./xml.md) | XML 标记语言 | 可扩展标记语言 |
| [.yaml](./yaml.md) | YAML 配置文件 | 可读性强的配置文件格式 |
| [.ini](./ini.md) | INI 配置文件 | 传统的配置文件格式 |
| [.sql](./sql.md) | SQL 数据库脚本 | 数据库查询和操作语言 |

## 学习建议

1. **新手入门推荐 Python**：语法简单，生态丰富，适合编程入门
2. **前端开发三件套**：HTML + CSS + JavaScript，学习网页开发必学
3. **系统/底层开发**：推荐学习 C/C++，性能强大但难度较高
4. **企业级开发**：Java 是企业应用的主流选择
5. **配置文件**：JSON 和 YAML 是目前最流行的两种格式
