# 小众图片与媒体格式

收录使用频率不如 JPG/PNG/MP3/MP4 普及，但在专业领域和特定场景中不可替代的图片、音频、视频格式。涵盖现代高效编码、专业摄影、游戏纹理、矢量印刷、无损音频、MIDI 音乐等。

## 分类简介

本分类收录了在专业领域和特定编码体系中使用的小众图片与媒体格式，包括：

- **现代高效图片**：HEIC、HEIF（新一代高压缩图片格式）
- **专业摄影**：RAW、CR2（相机原始数据，后期处理用）
- **游戏/纹理图片**：TGA、DDS（游戏开发和显卡纹理专用）
- **矢量印刷**：EPS（印刷出版领域的矢量格式）
- **音频编码**：OGG、AAC、WMA、APE、OPUS（不同压缩/无损音频方案）
- **视频格式**：WebM、WMV、MPG（容器与编码各异的视频格式）
- **音乐数据**：MID（MIDI 音乐指令文件）

## 使用建议

- **iPhone 用户图片**：HEIC 是默认格式，分享前可转 JPG 避免 Windows 兼容问题
- **摄影后期**：RAW/CR2 是数字底片，用 Lightroom/Capture One 处理
- **游戏开发**：TGA 用于带通道的贴图，DDS 用于实时渲染纹理
- **印刷出版**：EPS 用于矢量logo和印刷输出
- **听音乐**：APE 无损追求音质，OPUS 追求体积，AAC 通用兼容
- **在线视频**：WebM 是网页视频的开放选择
- **音乐制作**：MID 是编曲数据，需要音源才能发声
