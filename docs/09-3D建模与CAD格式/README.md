# 09 - 3D建模与CAD格式

本分类收录三维建模、计算机辅助设计（CAD）、3D打印和动画模型相关的文件格式。这些格式广泛应用于建筑工程、机械制造、工业设计、游戏开发、影视动画和3D打印等领域。

## 分类简介

3D建模与CAD文件格式可以大致分为三类：

- **工程CAD类**：如 DWG、DXF，主要用于建筑设计、机械制图，强调精确的几何尺寸和工程数据。
- **3D建模与动画类**：如 BLEND、FBX、MAX、OBJ，主要用于游戏、影视、艺术创作，强调视觉效果和动画。
- **3D打印与传输类**：如 STL、glTF，主要用于3D打印或网络传输，强调通用性和跨平台兼容。
