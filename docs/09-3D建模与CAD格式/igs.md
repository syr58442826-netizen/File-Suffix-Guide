# .igs / .iges 文件后缀详解

## 1. 文件定义 & 用途

IGS（又称 IGES，全称 Initial Graphics Exchange Specification，初始图形交换规范）是最早的 CAD 数据交换格式之一，由美国国家标准局（NIST，现 NIST）在 1980 年代初主导开发。它的出现是为了解决不同 CAD 系统之间无法交换数据的问题，是 CAD 数据交换领域的"开山鼻祖"。

IGES 格式的核心特点：
- **历史悠久**：1980 年发布首个版本，是最早的中性 CAD 交换格式
- **曲面为主**：主要用于交换曲面和线框数据，实体支持较弱
- **文本格式**：纯文本（ASCII）格式，可用记事本打开
- **应用广泛**：航空航天、汽车、机械等行业长期使用
- **逐渐被 STEP 取代**：STEP 格式功能更强大，IGES 正在逐步退出
- **兼容性好**：几乎所有 CAD 软件都支持 IGES，是"保底"格式

## 2. 适用场景

- **老 CAD 数据交换**：与老旧系统或传统行业（如航空航天）交换数据时常用 IGES
- **曲面数据传递**：传递自由曲面、复杂曲面模型时 IGES 仍然常用
- **跨平台兼容**：当 STEP 导入出问题时，IGES 有时是更稳定的选择
- **2D/3D 线框交换**：线框模型和工程图数据交换
- **传统行业协作**：某些老牌企业和机构仍然只接受 IGES 格式
- **格式考古**：处理八九十年代的老 CAD 文件

## 4. 如何编辑、如何导出

### 如何查看 IGES 文件

**在线查看（最快）：**
1. 打开 3D Viewer Online 或 ShareCAD 网站
2. 上传 IGS/IGES 文件
3. 在线旋转、缩放、查看

**使用 FreeCAD：**
1. 文件 → 打开 → 选择 .igs 文件
2. FreeCAD 会自动导入
3. 可以测量、剖切、导出为其他格式

### 如何导出 IGES 格式

**从 SolidWorks 导出：**
1. 文件 → 另存为
2. 保存类型选择 "IGES (*.igs; *.iges)"
3. 选项设置：
   - 曲面表示：MSBO（多曲面 B-Rep，推荐）
   - 输出坐标系
   - 实体/曲面选择
4. 点击保存

**从 FreeCAD 导出：**
1. 选中要导出的对象
2. 文件 → 导出
3. 选择 "IGES (*.igs *.iges)"
4. 点击保存

### IGES vs STEP 怎么选？

| 对比项 | IGES | STEP |
|--------|------|------|
| 发布时间 | 1980 年 | 1994 年 |
| 几何支持 | 曲面、线框为主 | 实体、曲面、装配都支持 |
| 装配信息 | 不支持 | 支持 |
| 颜色/层 | 有限支持 | 支持（AP214+） |
| 文件大小 | 相对较大 | 相对较小 |
| 稳定性 | 曲面交换稳定 | 实体交换更好 |
| 推荐场景 | 曲面传递、老系统兼容 | 实体模型、装配体交换 |

**一般建议：** 优先用 STEP，只有在以下情况用 IGES：
- 合作方明确要求 IGES
- STEP 导入失败但 IGES 可以
- 只需要传递曲面数据

### 格式转换

**IGES 转 STEP：**
- 用任意 CAD 软件打开 IGES → 另存为 STEP 即可
- 推荐 FreeCAD（免费）：打开后导出为 STEP with colors

**IGES 转 STL：**
1. FreeCAD：打开 IGES → Mesh Design 工作台 → 从形状创建网格 → 导出 STL
2. 注意：IGES 通常是曲面，转 STL 前可能需要先缝合成实体

## 5. 常见报错与解决

### 问题 1：导入 IGES 后模型有很多破面，不是封闭实体

**原因：** IGES 本质上是曲面格式，各个曲面之间可能有间隙，无法自动缝合成实体。

**解决方法：**
1. 这是 IGES 格式的正常现象，不是错误
2. 如果需要实体，可以用 CAD 软件的"缝合"（Sew）或"加厚"功能尝试修复
3. FreeCAD：Part 工作台 → 检查几何 → 尝试缝合
4. SolidWorks：输入诊断 → 尝试修复
5. 如果修复失败，可以考虑从源软件重新导出为 STEP 格式

### 问题 2：导入后某些曲面丢失或变形

**原因：** 不同 CAD 软件的几何内核对曲面的解析有差异，复杂的自由曲面可能解析不正确。

**解决方法：**
1. 从源软件重新导出时，尝试调整 IGES 导出选项（如曲面精度）
2. 尝试导出为不同的 IGES 版本
3. 换用 STEP 格式试试（STEP 的几何交换质量通常更好）
4. 如果必须用 IGES，可以尝试降低曲面复杂度后再导出

### 问题 3：IGES 文件打开后尺寸不对

**原因：** IGES 文件中可以指定单位，但有时单位信息丢失或不匹配。

**解决方法：**
1. 导入时注意选择正确的单位（mm、inch 等）
2. 导入后测量一个已知尺寸的特征，确认比例
3. 如果比例不对，可以整体缩放模型
4. 导出时建议使用毫米（mm），这是大多数行业的标准单位

### 问题 4：IGS 和 IGES 有什么区别？

**解答：** 没有区别，只是后缀不同而已。
- `.igs` 是三字母后缀（DOS 时代的遗留）
- `.iges` 是完整后缀名
- 内容和格式完全一样，软件都能识别
- 可以直接互相重命名

## 💡 小知识

IGES 是 CAD 数据交换的"老前辈"。在 1970 年代末到 1980 年代初，CAD 产业刚刚兴起，各家公司都有自己的格式，数据根本没法互通。美国空军为了解决这个问题（他们的供应商用各种不同的 CAD 系统），推动了 IGES 标准的开发。1980 年，IGES 1.0 版本正式发布。

IGES 最有意思的一个特点是它的文件格式——它是固定列宽的文本格式，就像早期的打孔卡片一样。每一行有 80 个字符，分成几个字段，每个字段有固定的位置。为什么是 80 字符？因为当年的 IBM 打孔卡片就是 80 列的。IGES 直接沿用了这个传统，所以你用记事本打开一个 IGES 文件，会看到每一行都是整整齐齐的 80 个字符。

虽然 IGES 在当年是革命性的，但它也有很多局限性——它主要支持曲面和线框，对实体模型的支持不好，装配体信息更是没法传递。所以后来才有了 STEP 格式（ISO 10303），它功能更强大、支持实体和装配，逐渐取代了 IGES 的地位。

不过即使到了今天，IGES 仍然没有完全消失。在航空航天、汽车等传统行业，很多老系统还在使用 IGES，而且对于纯曲面数据的交换，IGES 有时反而比 STEP 更稳定。就像一位虽然年迈但仍然坚守岗位的老工程师。
