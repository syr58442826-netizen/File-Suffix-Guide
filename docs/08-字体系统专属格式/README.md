# 字体系统专属格式

本分类涵盖了字体文件、系统核心文件和安全证书三类特殊格式。这些文件都有一个共同特点：它们是系统或软件运行的「基础设施」，普通用户平时很少直接操作，但理解它们的用途和安全风险非常重要。

## 分类简介

本分类收录了字体、系统文件和安全证书等特殊格式，包括：

- **字体文件类**：TTF、OTF（字体格式，用于文字显示）
- **系统文件类**：SYS、DLL（Windows 系统核心文件，注意安全风险）
- **证书密钥类**：PEM、CRT、KEY（安全证书和私钥文件，用于加密和身份验证）

> 安全提醒：SYS 和 DLL 是系统核心文件，**不要随意下载和替换**，否则可能导致系统崩溃或感染病毒。PEM/CRT/KEY 是安全证书和私钥文件，**私钥文件绝对不能泄露**，否则加密通信将不再安全。

## 后缀列表

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.ttf](./ttf.md) | TrueType 字体 | 最常用的字体格式，跨平台兼容 |
| [.otf](./otf.md) | OpenType 字体 | 功能更丰富的字体格式，支持高级排版 |
| [.sys](./sys.md) | 系统驱动文件 | Windows 系统驱动程序，控制硬件设备 |
| [.dll](./dll.md) | 动态链接库 | Windows 程序共享的函数库，注意安全风险 |
| [.pem](./pem.md) | PEM 证书文件 | 最常见的证书格式，用于 HTTPS/SSH 等 |
| [.crt](./crt.md) | 证书文件 | 数字证书，用于身份验证和加密通信 |
| [.key](./key.md) | 私钥文件 | 证书的私钥，极其重要，绝对不能泄露 |

## 使用建议

- **安装字体**：TTF 和 OTF 都可以直接安装，日常使用 TTF 即可，专业排版推荐 OTF
- **系统文件**：SYS 和 DLL 不要手动修改，出问题用系统工具修复
- **证书文件**：了解证书的用途和安全常识，保护好私钥文件
- **安全第一**：从不明来源下载的 .sys 和 .dll 文件很可能是病毒，务必警惕
