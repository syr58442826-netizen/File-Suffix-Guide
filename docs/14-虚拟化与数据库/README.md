# 虚拟化与数据库

本分类收录了虚拟化磁盘镜像、数据库文件以及相关二进制/链接协议的后缀。

> 虚拟化文件用于在不同虚拟机软件中保存虚拟磁盘；数据库文件用于持久化存储结构化数据。这些格式大多是二进制格式，需要专门的软件打开，不能直接用文本编辑器查看。

## 学习建议

1. **虚拟机入门**：VirtualBox 免费，先玩转 .vdi，再了解 VMware 的 .vmdk
2. **容器与虚拟机**：Docker 容器与传统虚拟机不同，但了解磁盘镜像有助理解
3. **数据库入门**：SQLite 是最好的入门数据库，单文件、零配置，推荐先学
4. **安全提醒**：torrent 和 magnet 链接本身是中性的文件分发技术，但下载内容受版权法约束，务必合法使用
5. **WebAssembly**：是前端性能优化的新方向，可让 C/C++/Rust 代码在浏览器运行
