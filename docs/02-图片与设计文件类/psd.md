# .psd 文件后缀详解

## 1. 文件定义 & 用途

PSD 是 **Photoshop Document** 的缩写，是 Adobe Photoshop 的原生文件格式。它最大的特点是支持图层——一张图片可以由很多图层叠加而成，每个图层可以独立编辑，是设计师最重要的工作文件格式。

- **全称**：Photoshop Document
- **类型**：图像设计源文件（位图为主，支持矢量元素）
- **开发者**：Adobe Systems
- **发布年份**：1990年（随 Photoshop 1.0 推出）
- **特点**：保留图层、蒙版、通道、样式、智能对象等所有编辑信息
- **支持**：图层、调整层、蒙版、通道、路径、文字、滤镜效果、3D 图层等

## 2. 适用场景

- 平面设计（海报、宣传单、名片、画册）
- UI 设计（App 界面、网页设计）
- 照片修图和合成
- 品牌设计（Logo 应用、视觉识别系统）
- 插画绘制（数字绘画）
- 设计稿交付（给开发人员切图和标注）

## 3. 推荐打开软件

| 平台 | 免费软件 | 专业软件 |
|------|----------|----------|
| Windows | GIMP（支持导入，图层部分支持）、Paint.NET（需插件）、Photopea（在线） | Adobe Photoshop、Affinity Photo、Corel PaintShop Pro |

**新手推荐**：

- 免费替代：**GIMP**（开源免费，能打开 PSD，部分图层支持）
- 绘画：**Krita**（免费开源，专为数字绘画设计）

## 4. 如何编辑、如何导出

### 如何编辑
1. 用 Photoshop 打开 .psd 文件
2. 在图层面板中选择要编辑的图层
3. 使用各种工具（画笔、选框、文字等）进行编辑
4. 调整图层顺序、透明度、混合模式
5. 按 `Ctrl + S` 保存（保留所有图层信息）

### 如何导出/转换
- **导出为 JPG/PNG**：
  - 文件 → 导出 → 快速导出为 PNG/JPG
  - 或文件 → 存储为 → 选择格式（会合并图层）
- **导出为 Web 格式**：文件 → 导出 → 存储为 Web 所用格式（可调节压缩参数）
- **PSD 转 PDF**：文件 → 存储为 → Photoshop PDF
- **PSD 转 SVG**：矢量图层可以导出为 SVG（文件 → 导出 → 路径到 Illustrator）
- **批量导出**：
  - 用动作（Action）批量处理
  - 用脚本（File → Scripts）
  - 切图神器：**Cutterman** 插件
- **保留图层交换**：另存为 TIFF 或 PSB（大文件格式）也能保留图层

## 5. 常见报错与解决

### 问题1：PSD 文件太大，打开和保存都很慢
**原因**：图层太多、分辨率太高、嵌入了大量智能对象或高清图片。

**解决方法**：
1. 合并不需要再编辑的图层（右键 → 合并图层）
2. 栅格化智能对象（但会失去可编辑性）
3. 图像 → 图像大小 → 降低分辨率（屏幕显示 72dpi 就够了）
4. 清理不需要的图层、样式、通道
5. 编辑 → 清理 → 全部（清理缓存，加速操作）
6. 文件太大（超过 2GB）时存为 .psb 格式（Photoshop Big）

---

### 问题2：打开 PSD 提示"缺少字体"，文字变成默认字体
**原因**：PSD 中使用了你的电脑上没有安装的字体。

**解决方法**：
1. 安装缺失的字体（从素材网站下载对应字体）
2. 点击"替换字体"，选择系统中有的类似字体代替
3. 如果不需要编辑文字，直接点确定即可（显示效果可能有变化）
4. 从 Adobe Fonts（Typekit）同步字体（需要 Creative Cloud 订阅）
5. 发送 PSD 给别人时，记得把字体一起发，或者把文字栅格化/转曲

---

### 问题3：PSD 文件损坏，打不开或提示"不是有效的 Photoshop 文档"
**原因**：保存时断电/崩溃、磁盘错误、病毒破坏、传输中断。

**解决方法**：
1. 找自动恢复文件：Photoshop → 编辑 → 首选项 → 文件处理 → 查看自动恢复文件位置
2. 用 GIMP 或 Photopea 试试能不能打开（有时候其他软件兼容性更好）
3. 用 PSD 修复工具（如 Stellar Repair for Photoshop、Recovery Toolbox）
4. 从备份或历史版本恢复
5. 开启"后台存储"和"自动保存"功能，减少损失

---

### 问题4：把 PSD 发给别人，对方看不到图层
**原因**：存成了 JPG/PNG 等扁平格式，或者对方用看图软件打开（不支持图层）。

**解决方法**：
1. 确认保存的是 .psd 格式，而不是 JPG/PNG
2. 对方需要用 Photoshop、GIMP 或 Photopea 等支持图层的软件打开
3. 如果只是看图，发 JPG/PNG 就够了
4. 如果需要对方编辑，一定要发 PSD 源文件
5. 可以同时发一份 JPG 预览图 + PSD 源文件，方便对方查看

## 💡 小知识

PSD 格式是 Adobe 的"护城河"之一。很多设计师离不开 Photoshop，不是因为它的修图功能无可替代，而是因为几十年积累下来的 PSD 源文件、素材库、模板都在这个格式里。PSD 文件里能存的东西远超你的想象——除了图层，还有蒙版、通道、路径、样式、智能对象、3D 模型、视频时间轴、甚至是笔记和元数据。所以一个复杂的 PSD 文件可能有上百个图层，体积达到几百 MB 甚至几个 GB。这也是为什么设计师的电脑总是需要大内存和快硬盘的原因。
