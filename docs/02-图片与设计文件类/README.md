# 图片与设计文件类

图片和设计文件是日常工作中最常接触的多媒体格式之一。从手机拍照到网页设计，从照片修图到品牌设计，不同的图片格式各有特点和适用场景。

## 分类简介

本分类收录了常见的图片和设计文件后缀，包括：

- **位图图片类**：JPG/JPEG、PNG、GIF、BMP、WebP、TIFF、AVIF
- **矢量图类**：SVG、AI、CDR
- **设计源文件类**：PSD、PSB、AI、CDR、Sketch、XCF
- **图标类**：ICO

## 后缀列表

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.jpg / .jpeg](./jpg.md) | JPEG 图片 | 最常见的有损压缩图片格式，适合照片 |
| [.png](./png.md) | PNG 图片 | 无损压缩，支持透明背景，适合图标和截图 |
| [.gif](./gif.md) | GIF 动图 | 支持动画和透明，色彩有限，适合简单动图 |
| [.bmp](./bmp.md) | 位图文件 | Windows 原生无压缩格式，体积大，质量高 |
| [.webp](./webp.md) | WebP 图片 | 谷歌推出的新一代图片格式，体积小质量好 |
| [.svg](./svg.md) | 可缩放矢量图 | 矢量格式，无限放大不失真，适合图标和插画 |
| [.psd](./psd.md) | Photoshop 文档 | Adobe Photoshop 的源文件格式，保留图层 |
| [.ai](./ai.md) | Illustrator 文档 | Adobe Illustrator 的矢量源文件格式 |
| [.cdr](./cdr.md) | CorelDRAW 文档 | CorelDRAW 的矢量设计源文件格式 |
| [.ico](./ico.md) | 图标文件 | Windows 图标格式，用于程序图标和网站图标 |
| [.tif / .tiff](./tif.md) | TIFF 图片 | 高质量无损格式，常用于印刷和专业摄影 |
| [.avif](./avif.md) | AVIF 图片 | 新一代图片格式，压缩率超高，现代浏览器支持 |
| [.sketch](./sketch.md) | Sketch 文档 | Mac 平台 UI 设计工具的源文件格式 |
| [.xcf](./xcf.md) | GIMP 图像文件 | 开源图像编辑器 GIMP 的原生格式，保留图层 |
| [.psb](./psb.md) | Photoshop 大型文档 | PSD 的大文件版本，支持超 2GB 文件 |

## 格式选择建议

- **照片和网页配图**：JPG（体积小）、WebP（体积更小）或 AVIF（体积最小）
- **截图和图标**：PNG（支持透明，无损）
- **动态表情包**：GIF
- **需要无限放大**：SVG（矢量图）
- **印刷出版**：TIFF 或高质量 PDF
- **设计源文件**：PSD/PSB（位图设计）、AI（矢量设计）、Sketch（UI 设计）
- **免费开源设计**：GIMP 的 XCF 格式
