# .jpg / .jpeg 文件后缀详解

## 1. 文件定义 & 用途

JPG（也写作 JPEG）是目前世界上最流行的图片格式，由联合图像专家组（Joint Photographic Experts Group）制定。它采用有损压缩算法，在保持较好视觉质量的同时大幅减小文件体积，特别适合照片和色彩丰富的图片。

- **全称**：Joint Photographic Experts Group
- **类型**：位图图片（有损压缩）
- **开发者**：JPEG 工作组
- **发布年份**：1992年
- **特点**：体积小、兼容性极强、支持百万级色彩、压缩后有轻微画质损失
- **后缀名**：.jpg 和 .jpeg 完全一样，只是写法不同（Windows 常用 .jpg）

## 2. 适用场景

- 手机拍照、数码相机照片
- 网页配图（产品图、banner、头像）
- 社交媒体分享（微信、微博、朋友圈）
- 邮件发送图片
- 打印照片（高质量模式）
- 一般的图片素材存储

## 4. 如何编辑、如何导出

### 如何编辑
1. 用图片编辑软件打开 JPG 文件
2. 进行裁剪、调色、加滤镜等操作
3. 保存时选择 JPG 格式，可调整压缩质量

### 如何导出/转换
- **转成 PNG**：用 Photoshop/画图/GIMP 打开 → 另存为 PNG
- **转成 GIF**：用 Photoshop 或在线工具转换
- **转成 WebP**：用 Photoshop 2022+ 或在线转换工具
- **转成 PDF**：右键 → 打印 → 选择 "Microsoft Print to PDF"
- **批量压缩**：用 **Squoosh**（谷歌在线工具）、**TinyPNG** 或批量处理脚本
- **调整质量**：保存 JPG 时可调整质量参数（通常 80-85% 是体积和质量的平衡点）

## 5. 常见报错与解决

### 问题1：JPG 图片打不开，提示"无法显示图片"或"文件损坏"
**原因**：文件下载不完整、存储介质损坏、病毒破坏等。

**解决方法**：
1. 重新下载或从备份恢复
2. 试试用不同软件打开（画图、Photoshop、浏览器）
3. 用在线修复工具（如 Office Recovery、Stellar Repair for Photo）尝试修复
4. 检查文件大小，如果只有几字节或异常小，说明文件已经损坏
5. 如果是从存储卡恢复的，试试用数据恢复软件（如 Recuva、DiskGenius）

---

### 问题2：JPG 图片越来越模糊，越保存越差
**原因**：JPG 是有损压缩，每次保存都会重新压缩一次，画质会逐渐下降。

**解决方法**：
1. 尽量减少保存次数，编辑完成后再保存
2. 编辑过程中保存为 PSD 或 PNG 格式，最后再导出 JPG
3. 保存时选择较高的质量（90% 以上）
4. 重要图片保留原始文件（RAW 或高质量 JPG）
5. 用"另存为"而不是直接覆盖保存，保留原始版本

---

### 问题3：图片太大，上传/发送不了
**原因**：JPG 分辨率太高或压缩比不够。

**解决方法**：
1. **在线压缩**：TinyPNG、Squoosh 等在线工具（操作简单，效果好）
2. **画图压缩**：Windows 画图 → 重新调整大小 → 降低像素 → 保存
3. **Photoshop**：文件 → 导出 → 存储为 Web 所用格式 → 调整质量
4. **批量压缩**：用 **RIOT**（Radical Image Optimization Tool）或脚本批量处理
5. 发朋友圈/微信时，直接在聊天窗口发送会自动压缩（但画质损失大）

---

### 问题4：图片方向不对，倒着或横着显示
**原因**：手机拍照时的方向信息（EXIF）没有被正确读取。

**解决方法**：
1. 用系统自带的照片查看器旋转后保存
2. 用画图打开 → 旋转 → 保存
3. 用 Photoshop 打开：图像 → 图像旋转 → 选择方向
4. 如果是网页显示，需要读取 EXIF 方向信息并自动旋转（很多网站已支持）
5. 手机拍照时注意握持方向，尽量横屏拍摄

## 💡 小知识

JPEG 的压缩算法非常聪明——它利用了人眼的一个"弱点"：人眼对亮度变化很敏感，但对颜色变化不那么敏感。所以 JPEG 压缩时，会保留亮度信息（Y 通道），而对颜色信息（Cb/Cr 通道）进行大幅压缩。这样压缩后，人眼几乎看不出差别，但文件体积却能缩小到原来的 1/10 甚至更小。这就是为什么同样一张照片，JPG 格式比 BMP 小那么多的原因。
