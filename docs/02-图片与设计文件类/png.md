# .png 文件后缀详解

## 1. 文件定义 & 用途

PNG 是 **便携式网络图形**（Portable Network Graphics）的缩写，是一种无损压缩的位图格式。它最大的特点是支持透明背景，而且压缩后不会损失画质，是网页设计和 UI 设计中最常用的格式之一。

- **全称**：Portable Network Graphics
- **类型**：位图图片（无损压缩）
- **开发者**：PNG 开发组
- **发布年份**：1996年
- **特点**：无损压缩、支持透明背景、支持 24 位真彩色、体积比 JPG 大
- **版本**：PNG-8（256色，类似 GIF）、PNG-24（真彩色，最常用）、PNG-32（真彩色+透明通道）

## 2. 适用场景

- 网页图标和 UI 元素（按钮、图标、Logo）
- 软件截图（文字清晰，无压缩失真）
- 需要透明背景的图片（Logo、水印、头像）
- 设计稿中的元素分层导出
- 文字较多的图片（如信息图、流程图）
- 中间过程的图片保存（避免反复保存损失画质）

## 4. 如何编辑、如何导出

### 如何编辑
1. 用图片编辑软件打开 PNG 文件
2. 编辑时注意保留透明通道
3. 保存时选择 PNG 格式

### 如何导出/转换
- **转成 JPG**：
  - 用 Photoshop/画图 打开 → 另存为 JPG
  - 注意：透明部分会变成白色或黑色
- **转成 WebP**：用 Photoshop 2022+ 或 Squoosh 在线转换
- **转成 GIF**：如果颜色简单，转 GIF 体积更小
- **转成 ICO**：用在线工具或专门软件（如 IcoFX）转换为图标
- **压缩 PNG**：
  - 在线工具：TinyPNG（效果最好，几乎看不出来损失）
  - 本地工具：**RIOT**、**PNGoo**
  - Photoshop：文件 → 导出 → 存储为 Web 所用格式 → 选 PNG-8 或 PNG-24
- **批量转换**：用 XnConvert 或 ImageMagick 命令行工具

## 5. 常见报错与解决

### 问题1：PNG 透明背景变成了白色/黑色
**原因**：查看软件不支持透明显示，或者粘贴到不支持透明的软件里了。

**解决方法**：
1. 确认查看软件支持透明（Windows 照片查看器旧版不支持，新版支持）
2. 用 Edge/Chrome 浏览器打开，可以正确显示透明
3. 如果是粘贴到 Word/PPT 里，选择"粘贴为图片"，背景会保持透明
4. 用 Photoshop 打开，检查图层面板，确认背景是透明的（棋盘格表示透明）

---

### 问题2：PNG 文件太大，上传太慢
**原因**：PNG 是无损压缩，照片类图片的 PNG 文件会比 JPG 大很多。

**解决方法**：
1. **在线压缩**：用 **TinyPNG**（强烈推荐，智能有损压缩，体积小很多）
2. 如果是照片，直接转成 JPG 格式（体积小 5-10 倍）
3. 如果是图标/截图，用 PNG-8 格式（256 色足够，体积小很多）
4. 调整图片尺寸，降低分辨率
5. 用 **ImageOptim**（Mac）或 **FileOptimizer**（Windows）进一步压缩

---

### 问题3：保存后的 PNG 图片有锯齿或白边
**原因**：透明边缘处理不好，或者从有背景的图抠图不干净。

**解决方法**：
1. 在 Photoshop 中抠图时，使用"调整边缘"或"选择并遮住"功能优化边缘
2. 导出时选择"PNG-24"格式，透明边缘更平滑
3. 不要存成 PNG-8（颜色太少，边缘会有锯齿）
4. 给图片加一个和使用背景相近的底色，可以减少锯齿感
5. 如果是 Logo 等矢量图形，建议用 SVG 格式（无限放大不失真）

---

### 问题4：手机上打开 PNG 显示异常或颜色不对
**原因**：PNG 的颜色配置文件（ICC Profile）不兼容，或者是特殊的 PNG 变体（如 APNG 动图）。

**解决方法**：
1. 用 Photoshop 重新保存：编辑 → 指定配置文件 → 选 sRGB
2. 导出为 Web 格式时勾选"转换为 sRGB"
3. 如果是 APNG（动态 PNG），需要用支持的浏览器或软件打开
4. 确认文件确实是 PNG，而不是其他格式改了后缀

---
## 💡 小知识

PNG 的诞生其实和 GIF 有关。1995年，Unisys 公司宣布对 GIF 格式中使用的 LZW 压缩算法收取专利费，这激怒了很多开发者。于是一群工程师决定开发一个完全免费、没有专利问题的新格式来替代 GIF——这就是 PNG。PNG 不仅免费，而且在很多方面都超越了 GIF：支持真彩色、支持 Alpha 透明通道、压缩率更高。唯一没继承的就是动画功能，不过后来也有了 APNG 扩展来支持动画。
