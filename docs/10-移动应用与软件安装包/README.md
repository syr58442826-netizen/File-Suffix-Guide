# 10 - 移动应用与软件安装包

本分类收录各类操作系统和平台的应用程序安装包格式，涵盖 Windows、macOS、Linux、Android、iOS 和 Java 平台。

## 分类简介

安装包文件是软件分发的核心载体。不同操作系统使用不同的安装包格式：

- **Windows**：MSI（Windows Installer）
- **macOS**：DMG（磁盘镜像）、PKG（安装包）
- **Linux**：DEB（Debian系）、RPM（Red Hat系）
- **Android**：APK（应用包）
- **iOS**：IPA（应用包）
- **Java平台**：JAR（Java归档）、WAR（Web应用归档）

---

## 安全提醒（重要）

安装包文件是恶意软件传播最常见的载体之一。使用本分类文件时请务必注意：

1. **只从可信来源下载**：官方应用商店（Google Play、App Store、Microsoft Store）或软件官方网站。不要从不明网站、网盘分享、论坛附件下载安装包。
2. **验证数字签名**：正规软件的安装包通常有数字签名，可在文件属性中查看发行者信息。如果签名无效或缺失，应高度警惕。
3. **安装前先扫描**：使用杀毒软件对安装包进行扫描。即使来源可信，也建议扫描后再运行。
4. **警惕破解版和汉化版**：破解版、绿色版、激活工具是木马的重灾区。能买正版就买正版，能找开源替代品就用开源替代品。
5. **移动端尤其注意权限**：APK 和 IPA 文件如果来自非官方渠道，可能被植入恶意代码。Android 安装非官方 APK 前请检查"未知来源"设置，iOS 非官方 IPA 需要越狱才能安装，风险更高。
6. **查看文件大小和哈希值**：正规下载站会提供文件的 MD5/SHA256 校验值，下载后请比对确认文件未被篡改。
