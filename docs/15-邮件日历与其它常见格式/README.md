# 邮件日历与其它常见格式文件后缀大全

本分类收录了电子邮件、日历日程、联系人名片、校验文件以及其它日常常见但不太好归类的文件格式，帮助你了解这些"杂项"格式的用途和用法。

## 分类简介

除了常见的文档、图片、视频格式之外，我们日常还会碰到各种"杂项"文件——收到的邮件附件、日历邀请、电子名片、下载到一半的文件、校验文件等等。这些格式各有各的用途，了解它们能帮你解决很多头疼的小问题。

本分类包括：

- **邮件类**：EML（通用邮件格式）、MSG（Outlook 邮件格式）
- **日历联系人**：ICS（日历日程）、VCF（电子名片）
- **帮助文档**：CHM（Windows 编译帮助）
- **漫画书**：CBR、CBZ（漫画书打包格式）
- **通用数据**：DAT（通用数据文件）、PART（下载未完成文件）
- **系统注册表**：REG（Windows 注册表导出文件）
- **Apple 配置**：PLIST（Apple 属性列表）
- **数据表格**：TSV（制表符分隔值）、ACCDB（Access 数据库）
- **校验文件**：MD5、SHA256（文件完整性校验）
- **信息文件**：NFO（信息文件）

## 快速选择指南

- **打开邮件附件**：EML 用邮件客户端或浏览器打开，MSG 需 Outlook 或转换工具
- **导入日历日程**：ICS 几乎所有日历 App 都支持，双击即可导入
- **导入联系人**：VCF 在手机和电脑上都支持，可直接添加到通讯录
- **查看软件帮助**：CHM 在 Windows 上双击即可，Mac/Linux 需第三方工具
- **看漫画**：CBZ 兼容性最好，CBR 需要解压软件支持 RAR 格式
- **校验文件完整性**：下载大文件时用 MD5 或 SHA256 校验确认文件没损坏
- **打开 DAT 文件**：DAT 格式不固定，需根据来源判断用什么软件打开
