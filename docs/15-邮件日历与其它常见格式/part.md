# .part 文件后缀详解

## 1. 文件定义 & 用途

PART 是**下载未完成文件**（Partial Download File）的后缀。当你用下载工具（如浏览器、迅雷、IDM 等）下载文件时，在下载完成之前，已下载的部分会以 `.part` 后缀保存在临时目录中。下载完成后，后缀会被自动改为正确的格式（如 .zip、.mp4 等）。

- **全称**：Partial Download File（部分下载文件）
- **类型**：下载临时文件
- **特点**：表示文件尚未下载完成，包含已下载的部分数据
- **产生原因**：下载中断、网络断开、手动暂停、下载工具崩溃等

PART 文件不是一种内容格式，而是下载软件的临时存储方式。不同下载工具的 PART 文件格式不同（有的直接是原始数据的截断，有的包含额外的元数据），所以一般只能在原下载工具中恢复继续下载。

## 2. 适用场景

- **中断下载恢复**：下载中途暂停或断网后，PART 文件保留了已下载进度
- **下载进度查看**：PART 文件的大小可以判断下载了多少
- **大文件分次下载**：暂停后继续，不需要从头重新下载
- **下载工具临时文件**：Firefox、迅雷、IDM 等下载工具使用 PART 文件

- 如果下载已完成但后缀还是 .part，手动改后缀试试
- 不要用不相关的软件强行打开（可能损坏数据）

## 4. 如何编辑、如何导出

### 如何恢复 PART 文件下载
1. **用原下载工具打开**：在下载工具中找到该下载任务，点击"继续/恢复"
2. **Firefox**：重新打开 Firefox → 下载列表 → 找到 .part 文件 → 继续
3. **迅雷/IDM**：打开下载工具 → 未完成任务 → 继续下载
4. **JDownloader**：打开 JDownloader → 找到暂停的任务 → 继续

### 如果下载已完成但后缀仍是 .part
这种情况说明文件数据已完整，只是下载工具没来得及改名：
1. 确认文件大小与目标文件大小一致
2. 将 `.part` 后缀直接改为正确后缀（如 `video.mp4.part` → `video.mp4`）
3. 尝试打开文件确认内容完整
4. 如果无法打开，说明数据可能不完整，需要重新下载

### 如何避免产生 PART 文件
- 确保网络稳定后再开始下载大文件
- 不要在下载过程中关闭下载工具
- 如果需要暂停，用下载工具的"暂停"功能而不是直接关闭程序
- 使用支持断点续传的下载工具（如 IDM、JDownloader）

## 5. 常见报错与解决

### 问题1：下载工具无法恢复 PART 文件继续下载
**原因**：下载链接已过期、服务器不支持断点续传、PART 文件损坏，或下载工具任务记录丢失。

**解决方法**：
1. 确认原下载链接是否还有效（有些下载链接有时效限制）
2. 确认服务器是否支持断点续传（部分 HTTP 服务器不支持 Range 请求）
3. 如果任务记录丢失：在下载工具中重新添加下载链接，指定到 PART 文件所在目录继续
4. 如果 PART 文件损坏，只能删除重新下载
5. 换一个支持断点续传的下载工具（如 IDM、JDownloader、aria2）

---

### 问题2：PART 文件占用空间很大，但不知道下载到哪了
**原因**：下载任务暂停或中断后，PART 文件保留在临时目录中，不知道是否可以删除。

**解决方法**：
1. 在下载工具中查看该任务的进度百分比和剩余大小
2. 如果下载已无法继续（链接过期/服务器不支持续传），可以删除 PART 文件释放空间
3. 如果是浏览器下载的：Chrome 的 PART 文件在下载文件夹，Firefox 在 `about:downloads` 中查看
4. 如果确定不需要继续下载，直接删除 PART 文件即可
5. 删除前确认：打开下载工具确认该任务是否还需要

---

### 问题3：PART 文件改后缀后无法打开
**原因**：文件数据不完整（下载并未真正完成），或者原始下载包含额外的元数据头导致文件不是标准的格式。

**解决方法**：
1. 检查文件大小是否与源文件一致——如果不一致说明没下完
2. 有些下载工具在 PART 文件头部存储了额外信息（如下载进度），直接改后缀可能打不开
3. 用十六进制编辑器查看文件头，确认是否以标准格式开头
4. 如果文件头不是标准格式开头，说明数据不完整，需要重新下载
5. 视频文件可以尝试用 VLC 播放器打开（VLC 能播放部分损坏的视频文件）
6. 压缩包文件如果只有部分数据，可能只能解压出一部分内容

---
## 💡 小知识

PART 文件是下载工具的"半成品"。就像做饭做到一半被叫走，锅里的食材还留着。下载工具用 PART 文件保存这些"半成品"，等你回来（恢复下载）时就能从断掉的地方接着来，而不用从头开始。

不过要注意，不是所有服务器都允许"接着来"——只有支持断点续传（HTTP Range 请求）的服务器才能从 PART 文件继续下载。如果服务器不支持，每次都得从头来，PART 文件就白存了。
