# .sha256 文件后缀详解

## 1. 文件定义 & 用途

SHA256 是 **SHA-256 校验文件**的后缀，用于存储目标文件的 SHA-256 哈希值（一个 64 位十六进制字符串）。与 MD5 类似，但 SHA-256 算法更安全、哈希值更长，是目前推荐的文件完整性校验标准。

- **全称**：SHA-256 Checksum File（SHA-256 校验文件）
- **类型**：校验/哈希文件
- **算法**：SHA-256（Secure Hash Algorithm 256-bit，安全哈希算法 256 位）
- **特点**：纯文本文件，内容为目标文件的 SHA-256 哈希值
- **安全性**：比 MD5 安全得多，目前无已知碰撞攻击

SHA256 文件和 MD5 文件的结构一样，就是一行文本，包含哈希值和文件名：
```
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855  myfile.zip
```

## 2. 适用场景

- **下载文件验证**：确认下载的系统镜像、安装包、固件等没有损坏
- **安全校验**：验证文件未被篡改（SHA-256 比 MD5 更安全）
- **软件发布**：开源软件和系统镜像发布时提供 SHA-256 校验值
- **区块链/密码学**：SHA-256 是比特币等区块链的核心算法之一
- **数字签名**：代码签名和数字证书使用 SHA-256 算法
- **密码存储**：部分系统用 SHA-256 存储密码哈希

## 4. 如何编辑、如何导出

### 如何打开 SHA256 文件
1. **记事本打开**：直接双击用记事本打开，看到一串 64 位字符的哈希值和文件名
2. **命令行校验**：
   - Windows：`Get-FileHash myfile.zip -Algorithm SHA256`（PowerShell）
   - Linux：`sha256sum myfile.zip`
   - Mac：`shasum -a 256 myfile.zip`
   - 对比输出的哈希值和 .sha256 文件中记录的值

### 如何生成 SHA256 校验文件
1. **命令行生成**：
   - Windows PowerShell：`Get-FileHash myfile.zip -Algorithm SHA256 | Out-File myfile.zip.sha256`
   - Linux/Mac：`sha256sum myfile.zip > myfile.zip.sha256`
2. **图形工具**：
   - HashTab：右键文件 → 属性 → 文件哈希 → 显示 SHA-256 值
   - 7-Zip：右键文件 → CRC SHA → SHA-256（显示后复制）
   - GtkHash（Linux）：拖入文件 → 选择 SHA-256 → 计算

### 如何校验文件完整性
1. 打开 .sha256 文件，记下里面记录的 64 位哈希值
2. 对目标文件计算当前的 SHA-256 值
3. 比较两个值：
   - **一致**：文件完整，未被损坏或篡改
   - **不一致**：文件已损坏或被修改，需要重新下载

### Windows PowerShell 一键校验
```powershell
# 计算并直接对比
$expected = "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
$actual = (Get-FileHash myfile.zip -Algorithm SHA256).Hash
if ($expected -eq $actual) { "校验通过" } else { "校验失败" }
```

## 5. 常见报错与解决

### 问题1：SHA-256 校验值不匹配
**原因**：文件在下载或传输过程中被损坏，或文件被修改过。

**解决方法**：
1. 重新下载文件（最常见的原因）
2. 检查是否从官方下载渠道获取（非官方渠道可能提供被修改的文件）
3. 尝试更换下载方式（换浏览器、换下载工具、换网络环境）
4. 如果使用 P2P/种子下载，确认种子来源可信
5. 如果文件从 U 盘/移动硬盘拷贝，检查存储设备是否有坏块
6. 如果校验值始终不匹配，联系发布方确认是否有更新

---

### 问题2：哈希值太长，手动对比容易出错
**原因**：SHA-256 有 64 个字符，肉眼对比容易看错。

**解决方法**：
1. 用工具自动校验（如 HashTab、GtkHash）：把 .sha256 文件和目标文件放一起，工具自动对比
2. Linux 一键校验：`sha256sum -c myfile.zip.sha256`（自动对比，输出 OK 或 FAILED）
3. Windows 用 `CertUtil`：`certutil -hashfile myfile.zip SHA256` 然后复制对比
4. 使用文本对比工具：把两个值分别粘贴到 Beyond Compare 或在线文本对比工具中
5. 编写脚本自动对比（如上面的 PowerShell 脚本）
6. 浏览器中用 JS 对比：将两个值粘贴到在线文本对比工具

---

### 问题3：打开 .sha256 文件后发现格式不对
**原因**：不同工具生成的校验文件格式略有差异（有的有文件名，有的只有哈希值）。

**解决方法**：
1. 常见格式1：`哈希值  文件名`（哈希值和文件名用空格分隔）
2. 常见格式2：`哈希值 *文件名`（用星号标记文件名是二进制模式）
3. 常见格式3：只有哈希值（没有文件名，需手动对比）
4. 如果文件名或哈希值被换行：用记事本打开检查格式，手动提取哈希值
5. 有些 .sha256 文件可能包含多个文件的校验值（每行一个），找到对应文件名的行
6. 如果格式特殊：用 `sha256sum -c` 命令尝试自动解析（它兼容多种格式）

## 💡 小知识

SHA-256 是美国国家安全局（NSA）设计的 SHA-2 哈希算法家族的一员，于 2001 年发布。与 MD5（128位、32字符）相比，SHA-256 产生 256 位（64 字符）的哈希值，安全性高得多——理论上需要 2^128 次运算才能找到碰撞，而 MD5 只需要几秒钟。

有趣的是，SHA-256 不仅仅是文件校验工具——它还是比特币区块链的核心算法。比特币挖矿本质上就是不断计算 SHA-256 哈希值，直到找到满足特定条件的值。所以每当你用 SHA-256 校验一个文件时，你实际上在运行和比特币挖矿相同的基础运算。

如今，越来越多的软件和系统发布时只提供 SHA-256 校验值而不再提供 MD5，因为 MD5 已被认为不够安全。如果你要发布文件给别人下载，建议提供 SHA-256 校验值。
