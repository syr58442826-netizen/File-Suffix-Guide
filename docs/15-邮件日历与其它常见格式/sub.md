# .sub 文件后缀详解

## 1. 文件定义 & 用途

SUB 是一种图形字幕格式，通常与 IDX 文件配对使用（称为 SUB/IDX 字幕）。SUB 文件存储的是字幕的图像数据（位图），而不是文本，因此它可以显示任何语言、任何字体样式的字幕，不受编码限制。这种字幕格式在 DVD 时代非常流行，因为它本质上就是 DVD 字幕的数字化版本。

SUB 格式的核心特点：
- **图形字幕**：字幕是图片（位图），不是文字，可以显示任意字形和特效
- **成对出现**：通常有一个 .sub 文件（图像数据）和一个 .idx 文件（索引文件），缺一不可
- **源于 DVD**：SUB/IDX 格式本质上是从 DVD 中提取的 VobSub 字幕
- **兼容性好**：几乎所有视频播放器都支持 SUB/IDX 字幕
- **体积较大**：因为是图片格式，体积比文本字幕（SRT、ASS）大很多
- **不可直接编辑**：不能用记事本编辑，需要专门的字幕编辑软件

## 2. 适用场景

- **DVD 字幕提取**：从 DVD 光盘中提取字幕，保存为 SUB/IDX 格式
- **老电影/动漫字幕**：早年的影视资源很多使用 SUB/IDX 格式的字幕
- **多语言字幕**：一个 SUB/IDX 文件可以包含多条语言轨道
- **特殊样式字幕**：需要显示特殊字体、颜色、特效的字幕（图形字幕不受字体限制）
- **字幕收藏归档**：原始 DVD 字幕的无损保存格式

## 4. 如何编辑、如何导出

### SUB/IDX 字幕怎么播放

**自动加载（最简单）：**
1. 确保 .sub 和 .idx 文件与视频文件同名，放在同一个文件夹
2. 例如：`movie.mp4` + `movie.sub` + `movie.idx`
3. 用播放器打开视频，字幕会自动加载
4. 可以在播放器的字幕菜单中切换语言轨道

**手动加载：**
1. 播放视频时，将 .idx 文件拖入播放器窗口
2. 或在播放器菜单中选择"载入字幕" → 选择 .idx 文件
3. 注意：要选 .idx 文件，不是 .sub 文件

### SUB/IDX 转 SRT（文本字幕）

SUB 是图形字幕，要转成文本字幕需要 OCR（光学字符识别）：

**使用 Subtitle Edit（推荐，免费）：**
1. 下载安装 Subtitle Edit
2. 文件 → 导入 → VobSub 字幕
3. 选择 .idx 文件
4. 软件会自动进行 OCR 识别
5. 检查并修正识别错误（OCR 不是 100% 准确）
6. 文件 → 另存为 → 选择 SRT 格式

**使用 SubRip（经典工具）：**
1. 打开 SubRip
2. 打开 .idx 文件
3. 设置识别语言
4. 开始处理，软件逐帧识别字幕文字
5. 人工校对后导出为 SRT

### 如何制作 SUB/IDX 字幕

**文本字幕转图形字幕：**
1. 用 Subtitle Edit 打开 SRT/ASS 字幕
2. 文件 → 导出 → VobSub
3. 设置字体、大小、颜色等样式
4. 导出为 .sub + .idx

**从 DVD 提取字幕：**
1. 使用 DVD Decrypter 或 MakeMKV 等工具
2. 选择字幕轨道
3. 提取为 SUB/IDX 格式

### SUB vs SRT vs ASS 怎么选？

| 对比项 | SUB（图形） | SRT（文本） | ASS（文本高级） |
|--------|-------------|-------------|-----------------|
| 格式类型 | 位图图片 | 纯文本 | 纯文本（带样式） |
| 体积 | 大（几 MB） | 小（几十 KB） | 小（几十 KB） |
| 编辑难度 | 难（需 OCR） | 简单（记事本） | 中等 |
| 字体样式 | 任意（位图） | 播放器决定 | 可自定义 |
| 多语言 | 支持（多轨道） | 多个文件 | 多个文件 |
| 适用场景 | DVD 原始字幕 | 通用字幕 | 特效字幕 |

## 5. 常见报错与解决

### 问题 1：SUB 字幕加载后不显示

**原因：** 缺少对应的 .idx 文件，或文件名不匹配，或字幕轨道不对。

**解决方法：**
1. 确认 .sub 和 .idx 文件都存在，且在同一目录
2. 确认两个文件名和视频文件名一致（除后缀外）
3. 确认文件没有损坏
4. 在播放器字幕菜单中检查是否选中了正确的字幕轨道
5. 尝试用其他播放器（如 VLC）播放，看是否是播放器的问题

### 问题 2：字幕显示乱码或花屏

**原因：** 字幕文件损坏，或播放器的字幕渲染器有问题。

**解决方法：**
1. 换用 VLC 或 PotPlayer 播放（兼容性最好）
2. 检查 .idx 和 .sub 文件是否完整（大小是否正常）
3. 尝试重新下载字幕文件
4. 调整播放器的字幕渲染设置（如 VLC 的字幕渲染器选项）

### 问题 3：想修改 SUB 字幕的文字，但用记事本打开是乱码

**原因：** SUB 文件是二进制的图像数据，不是文本，用记事本打开当然是乱码。

**解决方法：**
1. SUB 是图形字幕，不能直接编辑文字
2. 需要先用 OCR 软件（如 Subtitle Edit、SubRip）把图片转成文字
3. 转成 SRT 格式后才能编辑
4. 如果只是想改样式，不能改 SUB 本身，只能转成文本字幕再重新生成

### 问题 4：只有 .sub 文件没有 .idx 文件，字幕能用吗？

**原因：** .idx 是索引文件，记录了每条字幕的时间戳和位置信息，没有它播放器不知道什么时候显示哪条字幕。

**解决方法：**
1. 只有 .sub 文件通常无法正常使用
2. 尝试找对应的 .idx 文件（从下载字幕的地方重新下载）
3. 可以尝试用 Subtitle Edit 打开 .sub 文件，看能否重建索引
4. 如果实在找不到 .idx，建议直接找 SRT 格式的字幕

## 💡 小知识

SUB/IDX 字幕又叫 VobSub 字幕，它的诞生和 DVD 密不可分。DVD 上的字幕本身就是图像格式的——它们被存储在 DVD 的 VOB 文件中，是一张张叠加在视频上的小图片。这样做的好处是：无论你用什么语言、什么字体，都能完美显示，而且不需要考虑系统有没有安装对应字体。

后来有人开发了 VobSub 软件，可以把 DVD 上的字幕提取出来，保存成 .sub + .idx 两个文件。.sub 文件里存的就是字幕的图像数据（经过压缩），.idx 文件里存的是索引——告诉播放器第几条字幕在什么时候显示、在什么位置、是哪种语言。

在 2000 年代，SUB/IDX 格式非常流行，因为它能完美还原 DVD 的字幕效果，而且支持多语言（一个 SUB/IDX 文件里可以装好几条语言的字幕）。很多电影和动漫的字幕组都会发布 SUB/IDX 格式的字幕。

不过随着时间推移，文本字幕（SRT、ASS）逐渐取代了图形字幕的主流地位。原因很简单：文本字幕体积小（一部电影的 SRT 字幕只有几十 KB，而 SUB 可能有几 MB）、可以随便编辑和修改样式、而且在手机和平板上显示效果更好。

但 SUB/IDX 并没有完全消失——在一些对字幕样式要求高的场景（如蓝光原盘、DVD 复刻），图形字幕仍然有它不可替代的价值。
