# 科学与学术格式文件后缀大全

本分类收录了科学计算、学术研究、数据分析等领域常用的文件格式，帮助科研人员、学生和数据工作者了解这些专业格式的用途和用法。

## 分类简介

在科学研究和学术工作中，我们会接触到各种专业文件格式——从数值计算软件的数据文件，到学术论文的参考文献格式，再到大型科学数据集。这些格式各有特点，了解它们能帮助你更高效地进行科研和数据处理工作。

本分类包括：

- **MATLAB 数据/脚本**：MAT（MATLAB 数据文件）、M（MATLAB/Octave 脚本）
- **数学笔记本**：NB（Wolfram Mathematica 笔记本）
- **参考文献**：BIB（BibTeX 参考文献）
- **科学数据**：H5（HDF5 层次化数据格式）

## 快速选择指南

- **MATLAB 数据处理**：.mat 文件存数据，.m 文件写脚本
- **数学符号计算**：Mathematica 笔记本（.nb）适合公式推导和交互式计算
- **写论文参考文献**：用 BibTeX（.bib）管理参考文献，配合 LaTeX 使用
- **大型科学数据**：HDF5（.h5）适合存储海量多维数据和复杂数据结构
- **开源替代**：Octave 可以替代 MATLAB，Python + SciPy 也能处理 .mat 文件
