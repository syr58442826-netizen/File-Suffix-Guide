# .h5 文件后缀详解

## 1. 文件定义 & 用途

H5（又称 HDF5，Hierarchical Data Format version 5，层次化数据格式第5版）是一种用于存储和组织大型、复杂数据的文件格式和库。它由美国国家超级计算应用中心（NCSA）开发，被广泛用于科学计算、工程、天文、气象、生物信息等领域，用来存储海量的多维数据和复杂的数据结构。

HDF5 文件的核心特点：
- **层次化结构**：像文件系统一样，可以有组（Group）和数据集（Dataset）的嵌套结构
- **多维数据**：支持任意维度的数据集（标量、向量、矩阵、张量等）
- **大数据支持**：支持超大文件（TB 甚至 PB 级别）和部分读取
- **多种数据类型**：支持整数、浮点数、字符串、复合类型等
- **压缩支持**：内置多种压缩算法（gzip、szip 等），节省存储空间
- **跨平台**：Windows/Mac/Linux 都支持，语言绑定丰富（C、Python、R、MATLAB 等）
- **高性能**：优化的 I/O，支持并行读写，适合超算环境

## 2. 适用场景

- **科学数据存储**：物理、天文、气象、生物等领域的大型数据集
- **数值模拟**：保存仿真结果（流体力学、分子动力学、有限元等）
- **机器学习**：存储训练数据、模型权重、中间特征
- **遥感/地理信息**：卫星影像、地理空间数据
- **生物信息**：基因组数据、蛋白质结构、医疗影像
- **高性能计算**：超级计算机上的并行数据读写

## 4. 如何编辑、如何导出

### HDF5 文件的基本结构

HDF5 文件就像一个"文件系统中的文件系统"：
```
file.h5/
├── group1/
│   ├── dataset1    ← 数据集（多维数组）
│   ├── dataset2
│   └── subgroup/
│       └── dataset3
├── group2/
│   └── dataset4
└── dataset0        ← 根目录下的数据集
```

- **文件（File）**：.h5 文件本身
- **组（Group）**：类似文件夹，可以包含数据集和子组
- **数据集（Dataset）**：实际存储数据的地方，是一个多维数组
- **属性（Attribute）**：附加在组或数据集上的元数据（小数据）

### 用 Python 读写 HDF5 文件（h5py）

```python
import h5py
import numpy as np

# 创建 HDF5 文件
with h5py.File('data.h5', 'w') as f:
    # 创建数据集
    f.create_dataset('dataset1', data=np.array([1, 2, 3, 4, 5]))
    
    # 创建组
    grp = f.create_group('mygroup')
    
    # 在组里创建数据集
    grp.create_dataset('matrix', data=np.random.rand(100, 100))
    
    # 添加属性（元数据）
    f['mygroup/matrix'].attrs['description'] = '一个 100x100 的随机矩阵'
    f['mygroup/matrix'].attrs['created'] = '2024-01-01'

# 读取 HDF5 文件
with h5py.File('data.h5', 'r') as f:
    # 查看结构
    print(list(f.keys()))               # 查看根目录下的内容
    print(list(f['mygroup'].keys()))    # 查看组内的内容
    
    # 读取数据集
    data = f['dataset1'][:]             # 读取全部数据
    print(data)
    
    # 部分读取（不用全部加载进内存）
    matrix = f['mygroup/matrix']
    subset = matrix[0:10, 0:10]         # 只读取前 10 行 10 列
    
    # 读取属性
    desc = f['mygroup/matrix'].attrs['description']
    print(desc)
```

### 用 MATLAB 读写 HDF5 文件

```matlab
% 写入 HDF5 文件
data = rand(100, 100);
h5create('data.h5', '/mygroup/matrix', size(data));
h5write('data.h5', '/mygroup/matrix', data);

% 添加属性
h5writeatt('data.h5', '/mygroup/matrix', 'description', '随机矩阵');

% 读取 HDF5 文件
data = h5read('data.h5', '/mygroup/matrix');

% 查看文件结构
h5disp('data.h5');
```

### 用命令行工具查看

```bash
# 查看文件结构
h5ls -r data.h5

# 查看详细信息（包括数据）
h5dump data.h5

# 只查看某个数据集
h5dump -d /mygroup/matrix data.h5

# 查看属性
h5dump -a /mygroup/matrix/description data.h5
```

## 5. 常见报错与解决

### 问题 1：HDF5 文件太大，读取时内存不够

**原因：** 数据集太大，一次性加载到内存中超出了可用内存。

**解决方法：**
1. 使用部分读取（切片操作），只读取需要的数据：
   ```python
   with h5py.File('big.h5', 'r') as f:
       # 只读前 100 行
       subset = f['large_dataset'][0:100, :]
   ```
2. 确保数据集是分块存储的（chunked），这样才能高效部分读取
3. 使用迭代器逐块处理数据
4. 增加计算机内存，或使用更高配置的机器
5. 考虑数据压缩，减小文件体积

### 问题 2：HDF5 文件损坏，无法打开

**原因：** 写入过程中程序崩溃、断电、磁盘错误等。

**解决方法：**
1. 重要数据一定要有备份
2. 写入时使用 HDF5 的"文件空间管理"选项，降低损坏风险
3. 尝试用 h5debug 工具诊断（但修复能力有限）
4. 写入完成后用 h5ls 或 h5dump 验证文件完整性
5. 对于非常重要的数据，考虑写入完成后再重命名（原子操作）

### 问题 3：Python 的 h5py 和 MATLAB 读写的 HDF5 互不兼容

**原因：** 主要是字符串编码和数据类型的差异。

**解决方法：**
1. 数值数据通常完全兼容
2. 字符串可能有编码问题：
   - Python 中使用 `dtype=h5py.string_dtype(encoding='utf-8')`
   - MATLAB 中注意字符串的读写方式
3. 结构体/复合类型的映射需要注意
4. 推荐以数值为主，元数据用属性存储，减少兼容性问题

### 问题 4：HDF5 和 MAT、CSV、NPY 怎么选？

**解答：** 不同场景选不同的格式：
- **小数据、简单数据**：CSV（最通用）或 NPY（NumPy 专用，速度快）
- **MATLAB 生态**：.mat 格式（和 MATLAB 无缝衔接）
- **大型多维数据、复杂结构**：HDF5（功能最强，支持压缩和部分读取）
- **跨语言共享**：HDF5（几乎所有语言都支持）
- **超大规模/并行计算**：HDF5（高性能 I/O、并行读写）

## 💡 小知识

HDF5 的历史要从 HDF 说起。HDF（Hierarchical Data Format）最早是美国国家超级计算应用中心（NCSA）在 1980 年代末开发的。那时候超级计算正在兴起，但数据存储是个大问题——不同软件用不同的格式，数据交换困难，而且海量数据的存储和读取效率很低。

NCSA 的解决方案就是 HDF——一种灵活、高效、层次化的数据格式。HDF 的设计理念是"像文件系统一样组织数据"——你可以有文件夹（组）、文件（数据集），每个文件里可以是任意维度的数组。这个设计非常灵活，几乎能装任何类型的科学数据。

HDF5 是第五代 HDF 格式（所以叫 HDF5），也是最成功的一代。它在 1998 年左右发布，相比之前的版本，HDF5 做了大量改进：更好的性能、更大的文件支持、更丰富的数据类型、内置压缩、并行 I/O 支持等等。

现在 HDF5 已经成了科学数据存储领域的"工业标准"。NASA 用它存卫星数据，CERN 用它存粒子物理数据，气象部门用它存气象模型输出，生物学家用它存基因数据……几乎所有需要处理大量科学数据的领域，都能看到 HDF5 的身影。

有趣的是，HDF5 还有一个"明星亲戚"——它是 MATLAB v7.3 版 .mat 文件的底层格式。没错，从 MATLAB 7.3 开始，.mat 文件内部其实就是 HDF5 格式（加了一些 MATLAB 特有的元数据）。所以你用 h5py 也能读取 v7.3 的 .mat 文件。这也从侧面说明了 HDF5 的强大和通用性——连 MathWorks 都选择用它作为新一代 MAT 格式的基础。
