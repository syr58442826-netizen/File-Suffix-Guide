# .xlsm 文件后缀详解

## 1. 文件定义 & 用途

XLSM 是 **Excel Macro-Enabled Workbook** 的缩写，是 Microsoft Excel 的宏启用工作簿格式。它和 .xlsx 几乎完全一样，区别在于 .xlsm 文件可以包含 VBA 宏代码。

简单来说，.xlsm = .xlsx + VBA 宏代码。Excel 中的宏可以自动执行复杂的数据处理任务，比如批量计算、自动生成图表、数据清洗、定时刷新报表等。

- **全称**：Microsoft Excel Macro-Enabled Workbook
- **类型**：电子表格文档（含 VBA 宏代码）
- **开发者**：Microsoft（微软）
- **发布年份**：2007年（随 Office 2007 推出）
- **特点**：与 xlsx 功能一致，额外支持嵌入 VBA 宏脚本

## 2. 适用场景

- 带自动化脚本的财务模型和报表模板
- 需要按钮/下拉框等交互控件的数据录入表单
- 批量数据处理和格式化的工作簿
- 带自定义函数（UDF）的复杂计算表格
- 定时自动刷新数据的看板和仪表盘

## 3. 推荐打开软件

| 平台 | 免费软件 | 专业软件 |
|------|----------|----------|
| Windows | WPS Office 免费版、LibreOffice Calc | Microsoft Excel、WPS Office 专业版、Office 365 |
| Mac | LibreOffice Calc、Numbers（不支持宏） | Microsoft Excel for Mac |
| Linux | LibreOffice Calc、Gnumeric | - |

**新手推荐**：
- 用宏功能：**Microsoft Excel**（宏兼容性最好）
- 免费替代：**LibreOffice Calc**（支持 VBA 宏导入，但部分高级宏可能不兼容）
- 在线查看：**Microsoft 365 在线版**（查看数据可以，但宏功能有限）

## 4. 如何编辑、如何导出

### 如何编辑
1. 双击 .xlsm 文件用 Excel 打开
2. 顶部出现"安全警告 - 宏已被禁用"时，点击"启用内容"
3. 编辑表格数据与普通 Excel 操作一致
4. 编辑宏代码：按 `Alt + F11` 打开 VBA 编辑器
5. 按 `Ctrl + S` 保存（保留宏代码）

### 如何导出/转换
- **转成 xlsx（去掉宏）**：文件 → 另存为 → Excel 工作簿 (*.xlsx)，宏代码会被去除
- **转成 PDF**：文件 → 导出 → 创建 PDF/XPS
- **转成 CSV**：文件 → 另存为 → CSV（只保留当前工作表数据，丢失宏和格式）
- **导出宏模块**：在 VBA 编辑器中右键模块 → 导出文件 (.bas)

## 5. 常见报错与解决

### 问题1：打开时宏不运行，提示"宏已被禁用"
**原因**：Excel 默认安全设置禁用宏，需要手动启用。

**解决方法**：
1. 点击文档顶部黄色提示栏的"启用内容"按钮
2. 如果没有提示栏，去 文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置，选择"禁用所有宏，并给出通知"
3. 将文件所在文件夹添加到受信任位置
4. 确认文件可信后再启用

---

### 问题2：宏运行报错"下标越界"或"类型不匹配"
**原因**：宏代码引用了不存在的 worksheet 名称、数组越界，或数据结构与编写宏时不一致。

**解决方法**：
1. 按 `Alt + F11` 打开 VBA 编辑器，点击"调试"定位报错行
2. 检查 worksheet 名称是否与代码中引用的一致（有人改了 sheet 名）
3. 检查数据范围是否有空行或格式异常
4. 在代码中增加错误处理 `On Error Resume Next` 或 `On Error GoTo ErrorHandler`

---

### 问题3：打开 xlsm 提示"文件格式和扩展名不匹配"
**原因**：文件可能损坏、下载不完整，或者实际是其他格式被改了后缀。

**解决方法**：
1. 重新下载或复制文件
2. 尝试用 LibreOffice Calc 打开（有时修复能力更强）
3. 用 Excel 的"打开并修复"功能：文件 → 打开 → 选中文件 → 点"打开"旁箭头 → 打开并修复
4. 如果能打开，立即另存为新的 xlsm 文件

---

### 问题4：另存为 xlsx 后宏和按钮全部消失
**原因**：xlsx 格式不支持宏，另存时会自动去除所有 VBA 代码和交互控件。

**解决方法**：
1. 需要保留宏就必须保存为 .xlsm 格式
2. 如果确实要去掉宏只留数据，xlsx 是正确选择
3. 兼容旧版 Excel 可存为 .xls（97-2003）格式，同时保留宏

---

## ⚠️ 宏安全风险（重点）

.xlsm 文件是 Excel 中最常见的恶意代码载体，**宏病毒和木马经常通过 xlsm 文件传播**。请务必注意：

1. **不要随意启用陌生文件的宏**：邮件附件中的 .xlsm 文件是高危对象，尤其是主题为"发票""对账单""工资表"等诱导性名称的文件
2. **典型攻击方式**：攻击者发送包含恶意宏的 xlsm 文件，一旦启用宏，代码会下载并安装木马、勒索软件或窃取器
3. **永远不要把宏安全级别设为最低**：保持"禁用所有宏，并给出通知"的默认设置
4. **只信任自己编写的宏**：别人发来的宏文档，先在沙箱环境中测试再使用
5. **警惕诱导性提示**：恶意文档通常会在文档中放置"请启用宏以查看完整内容"的提示文字，这是常见的社会工程学手法
6. **配合杀毒软件**：确保杀毒软件已开启实时保护，对邮件附件自动扫描

## 💡 小知识

Excel 宏在金融和数据分析行业使用极其广泛，很多投资银行和会计师事务所的复杂模型都是用 xlsm 文件构建的。一个熟练的 Excel VBA 开发者可以写出功能堪比小型软件的宏工作簿。但也正因为如此，xlsm 文件成了黑客的重点目标——据统计，超过 60% 的企业钓鱼邮件攻击使用包含恶意宏的 Office 文件。
