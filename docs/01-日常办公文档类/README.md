# 日常办公文档类

日常办公中最常见的文档格式，涵盖文本处理、电子表格、演示文稿、电子书等类型。掌握这些文件格式的特点和使用方法，能大大提高工作效率。

## 分类简介

本分类收录了在日常办公、学习和阅读中最常遇到的文档类文件后缀，包括：

- **纯文本类**：TXT、MD（Markdown）、LOG
- **文字处理类**：DOC、DOCX、DOCM、WPS
- **电子表格类**：XLS、XLSX、XLSM、CSV、ODS
- **演示文稿类**：PPT、PPTX、PPTM、ODP
- **阅读/版式类**：PDF、EPUB、MOBI、XPS

## 使用建议

- **日常写作**：推荐使用 DOCX 或 MD，兼容性好且功能丰富
- **数据处理**：XLSX 是首选，CSV 适合数据交换
- **正式分发**：PDF 是最佳选择，确保格式不被修改
- **电子书阅读**：EPUB 是通用标准，MOBI 适用于 Kindle 设备
