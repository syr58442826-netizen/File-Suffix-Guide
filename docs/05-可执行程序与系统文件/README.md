# 可执行程序与系统文件

本分类收录了与程序运行、系统操作相关的常见文件后缀。

> **安全提醒：可执行文件具有运行代码的能力，可能对系统造成危害。请始终从可信来源获取可执行文件，运行前建议使用杀毒软件扫描。不要随意双击来源不明的 .exe、.bat、.cmd、.sh 等文件！**

## 后缀列表

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.exe](./exe.md) | Windows 可执行程序 | Windows 平台最常见的可执行文件格式 |
| [.bat](./bat.md) | DOS 批处理文件 | Windows 下的简单脚本文件，由一系列命令组成 |
| [.cmd](./cmd.md) | Windows 命令脚本 | 与 .bat 类似，基于 Windows NT 命令解释器 |
| [.lnk](./lnk.md) | Windows 快捷方式 | 指向其他文件或程序的快捷链接 |
| [.sh](./sh.md) | Shell 脚本 | Linux/Mac 下的脚本文件，由 Bash 等 Shell 解释执行 |
| [.run](./run.md) | Linux 安装包 | Linux 下常见的自解压安装包格式 |
| [.out](./out.md) | Unix 可执行文件 | Unix/Linux 下编译器默认生成的可执行文件 |
| [.bin](./bin.md) | 二进制文件 | 通用二进制可执行文件或数据文件 |
| [.com](./com.md) | DOS 命令文件 | DOS 时代可执行格式，64 位 Windows 需 DOSBox 运行 |
| [.scr](./scr.md) | 屏幕保护程序 | 本质是可执行文件，伪装成屏保，安全风险高 |

## 安全使用建议

1. **来源验证**：只从官方网站或可信渠道下载可执行文件
2. **杀毒扫描**：运行前用杀毒软件扫描，特别是 .exe 和 .bat 文件
3. **右键查看**：收到可疑文件时，先右键查看属性，不要直接双击
4. **沙箱运行**：不确定安全性时，可在虚拟机或沙箱软件中测试
5. **备份数据**：运行陌生程序前，务必备份重要数据
