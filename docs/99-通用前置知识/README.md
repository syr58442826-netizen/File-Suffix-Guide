# 通用前置知识 —— 新手必看

> ⚠️ **重要提示**：如果你是电脑新手，在浏览其他章节之前，请务必先阅读本模块的内容。很多"文件打不开"的问题，本质上都是因为不了解文件后缀的基本原理。

---

## 为什么要先看这个模块？

在日常使用电脑的过程中，你可能遇到过这些问题：

- 下载了一个文件，不知道用什么软件打开
- 改了文件名后缀，文件就打不开了
- 别人发来的文件在他电脑上正常，到你这就乱码
- 同样的文件，Windows 能打开，Mac 打不开

这些问题的根源，都和**文件后缀**以及**跨平台差异**有关。花 10 分钟读完本模块，能帮你避开 90% 的文件相关坑。

## 快速自检：你需要看这个模块吗？

回答以下问题，如果有任何一个答不上来，建议你认真读完本模块：

- [ ] 为什么同一个文本文件，在 Windows 和 Mac 上打开可能会乱码？
