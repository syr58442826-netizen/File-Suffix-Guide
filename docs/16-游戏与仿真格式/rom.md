# .rom 文件后缀详解

## 1. 文件定义 & 用途

ROM（Read-Only Memory，只读存储器镜像）是游戏机或老电脑系统的 ROM 芯片数据的镜像文件。简单来说，就是把游戏机卡带或主板上的 ROM 芯片里的数据完整地"读"出来，保存成一个文件。这个文件就叫 ROM 文件，可以在模拟器中运行，实现"在电脑上玩老游戏"。

ROM 文件的核心特点：
- **游戏镜像**：完整复制游戏卡带/光盘的数据
- **模拟器运行**：需要配合对应平台的模拟器才能玩
- **格式多样**：不同平台的 ROM 格式不同（NES、GBA、SNES 等各有各的格式）
- **收藏价值**：很多游戏爱好者收藏经典游戏的 ROM 文件
- **版权争议**：ROM 文件的法律地位在不同国家有不同规定
- **复古游戏**：主要用于在现代设备上玩老游戏

## 2. 适用场景

- **复古游戏游玩**：在电脑、手机、掌机上用模拟器玩老游戏
- **游戏收藏**：收藏经典游戏的 ROM 镜像
- **游戏研究**：研究老游戏的代码、美术、音乐等
- **游戏修改/汉化**：对 ROM 进行修改、翻译、制作 MOD
- **跨平台体验**：在没有原主机的情况下体验老游戏
- **游戏开发参考**：学习老游戏的设计和实现

## 3. 推荐打开软件

| 平台 | 免费软件 | 专业软件 |
|------|----------|----------|
| Windows | RetroArch（多合一模拟器）、各平台专用模拟器 | - |

**注意：** ROM 文件需要用对应平台的模拟器打开。不同游戏机的 ROM 不能通用。

常见游戏机及模拟器：
- **NES/FC（红白机）**：Nestopia、FCEUX、Mesen
- **SNES/SFC（超级任天堂）**：Snes9x、bsnes、ZSNES
- **GBA（Game Boy Advance）**：VisualBoyAdvance、mGBA、My Boy!
- **PS1**：ePSXe、DuckStation、Mednafen
- **街机（MAME）**：MAME、FB Alpha
- **多平台合一**：RetroArch、OpenEmu

## 4. 如何编辑、如何导出

### 如何用模拟器运行 ROM

**通用步骤：**
1. 下载对应平台的模拟器（如玩 GBA 游戏就下 GBA 模拟器）
2. 安装并打开模拟器
3. 文件 → 打开 ROM → 选择 .rom 文件（或对应平台格式的文件）
4. 开始游戏

**使用 RetroArch（推荐，一个软件玩所有平台）：**
1. 下载安装 RetroArch
2. 在线更新 → 更新核心（下载对应游戏机的模拟器核心）
3. 加载核心 → 选择对应平台的核心
4. 加载内容 → 选择 ROM 文件
5. 开始游戏

### ROM 文件格式一览

不同游戏机的 ROM 后缀各不相同：
| 游戏机 | 常见后缀 | 说明 |
|--------|----------|------|
| NES/FC | .nes | 任天堂红白机 ROM |
| SNES/SFC | .smc / .sfc | 超级任天堂 ROM |
| Game Boy | .gb | Game Boy 初代 ROM |
| GBC | .gbc | Game Boy Color ROM |
| GBA | .gba | Game Boy Advance ROM |
| N64 | .n64 / .z64 / .v64 | 任天堂64 ROM |
| PS1 | .bin + .cue / .iso / .img | PlayStation 1 光盘镜像 |
| 街机 | .zip（MAME ROM集） | MAME 街机 ROM |
| Genesis/MD | .md / .gen | 世嘉五代/MD ROM |

**注意：** .rom 后缀有时用作通用后缀，但大多数游戏机 ROM 有自己特定的后缀。

### ROM 文件的大小

不同平台的 ROM 大小差异很大：
- **红白机（NES）**：8KB ~ 1MB（大多 128KB ~ 512KB）
- **Game Boy**：32KB ~ 8MB
- **GBA**：4MB ~ 32MB
- **SNES**：256KB ~ 6MB
- **PS1**：几百 MB ~ 650MB（光盘镜像）
- **街机**：几 KB ~ 几百 MB 不等

### 如何提取 ROM（dump）

从实体卡带/光盘中提取 ROM 的过程叫 "dump"（转储）：

**卡带 ROM 提取：**
1. 需要专用的 ROM 读取器（如 Retrode、GBxCart 等）
2. 把卡带插入读取器
3. 连接电脑，用软件读取 ROM 数据
4. 保存为 ROM 文件

**光盘游戏提取：**
1. 用电脑光驱（PS1 等老光盘游戏）
2. 使用软件（如 ImgBurn、CDRDAO）制作光盘镜像
3. 保存为 .bin/.cue 或 .iso 格式

## 5. 常见报错与解决

### 问题 1：模拟器打不开 ROM 文件，提示"不支持的格式"

**原因：** ROM 格式和模拟器不匹配，比如用 NES 模拟器打开 GBA 的 ROM。

**解决方法：**
1. 确认你的 ROM 是哪个平台的游戏
2. 下载对应平台的模拟器
3. 或使用 RetroArch（多平台合一，自动识别）
4. 检查 ROM 文件后缀是否正确（.nes 是 NES 游戏，.gba 是 GBA 游戏）

### 问题 2：ROM 文件运行后花屏、黑屏或卡顿

**原因：** ROM 文件损坏、模拟器设置不对，或模拟器兼容性问题。

**解决方法：**
1. 尝试换一个模拟器（不同模拟器兼容性不同）
2. 检查 ROM 文件是否完整（和已知的 GoodSet 对比 MD5）
3. 调整模拟器设置（视频渲染、音频同步等）
4. 确认模拟器 BIOS 文件配置正确（部分模拟器需要 BIOS）
5. 使用 RetroArch 的不同核心试试

### 问题 3：不知道这个 ROM 是什么平台的游戏

**原因：** 只有一个 .rom 文件，不知道是什么游戏机的。

**解决方法：**
1. 看文件名——大多数 ROM 文件名会包含平台信息
2. 看文件大小——NES 一般几百 KB，GBA 几 MB 到几十 MB
3. 看文件头——用十六进制编辑器打开，不同平台的 ROM 有不同的文件头
4. 用 ROM 管理工具（如 Romcenter、ClrMamePro）识别
5. 直接用 RetroArch 试试能不能加载，它会尝试自动识别

### 问题 4：下载的 ROM 是压缩包，怎么用？

**原因：** ROM 文件通常会被压缩成 ZIP 或 RAR 格式以节省空间。

**解决方法：**
1. 大多数模拟器支持直接读取 ZIP 压缩的 ROM（不用解压）
2. 如果模拟器不支持，先解压再加载
3. 街机 ROM 通常保持 ZIP 格式，不要解压
4. 注意：有些 ROM 集（如 MAME）需要保持特定的文件名和结构

## 💡 小知识

ROM 文件的故事要从"ROM"这个词说起。ROM 是 Read-Only Memory（只读存储器）的缩写，是一种只能读取、不能修改的存储芯片。老游戏卡带里就有 ROM 芯片，游戏程序和数据都烧录在里面。插卡带的本质，就是把 ROM 芯片接到游戏机上。

后来有技术牛人研究出了怎么把卡带里的 ROM 数据"读"出来，保存成电脑上的文件——这就是 ROM 文件的由来。这个过程叫 "dumping"（转储）。再后来，有人写出了能在电脑上模拟游戏机硬件的软件——模拟器。把 ROM 文件加载进模拟器，就能在电脑上玩老游戏了。

ROM 和模拟器的出现，对电子游戏历史的保存做出了巨大贡献。很多老游戏的实体卡带已经越来越少，甚至有些已经失传。而 ROM 文件让这些经典游戏得以在数字世界中"永生"。

不过 ROM 文件也一直伴随着版权争议。在大多数国家，你可以为了备份你自己拥有的游戏而制作 ROM，但分享或下载别人的 ROM 是违法的。当然，现实情况要复杂得多——很多已经停产几十年的老游戏，版权方早就没了，这些游戏的 ROM 更多的是一种文化遗产。

有趣的是，现在很多游戏公司也开始重视老游戏的价值了。任天堂的 NSO 会员服务、索尼的 PS Plus 经典游戏、各种复古迷你主机……官方的"合法模拟器"越来越多。但对于真正的复古游戏爱好者来说，收集 ROM 和研究模拟器，本身就是一种乐趣。
