# 游戏与仿真格式文件后缀大全

本分类收录了游戏存档、游戏 ROM、游戏资源包等与电子游戏和仿真相关的文件格式，帮助你了解各种游戏文件的用途和处理方法。

## 分类简介

游戏文件是很多电脑用户经常接触但又不太了解的一类文件。从下载的游戏 ROM 到游戏存档，从游戏资源包到模拟器文件，各种格式让人眼花缭乱。了解这些格式的特点和用途，可以帮助你更好地管理游戏资源、解决游戏运行问题。

本分类包括：

- **游戏存档**：SAV（通用游戏存档）
- **游戏 ROM**：ROM（通用 ROM 镜像）、NES（红白机 ROM）、GBA（Game Boy Advance ROM）
- **游戏资源包**：VPK（Valve Pak 资源包）、WAD（DOOM WAD 文件）

## 快速选择指南

- **想玩老游戏**：下载对应平台的 ROM 文件 + 模拟器（NES 用 Nestopia，GBA 用 VisualBoyAdvance）
- **游戏存档在哪**：不同游戏存档位置不同，通常在游戏安装目录或"我的文档"中
- **游戏 MOD**：很多游戏的 MOD 是替换或添加游戏资源包（如 WAD、VPK）
- **模拟器使用**：下载 ROM 文件后，用模拟器打开即可游玩
- **注意版权**：请确保你拥有游戏原版的合法版权，ROM 文件仅供个人备份使用
