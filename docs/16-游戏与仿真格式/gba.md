# .gba 文件后缀详解

## 1. 文件定义 & 用途

GBA 文件是任天堂 Game Boy Advance（简称 GBA，游戏男孩 Advance）掌机的游戏 ROM 镜像文件。它包含了完整的 GBA 游戏程序和数据，可以在 GBA 模拟器中运行，或在烧录卡上运行。GBA 是 2000 年代最受欢迎的掌机之一，拥有大量经典游戏。

GBA 格式的核心特点：
- **GBA 掌机专属**：任天堂 Game Boy Advance 的 ROM 格式
- **32 位掌机**：GBA 是 32 位掌机，游戏画面和容量都比前代大幅提升
- **体积适中**：ROM 大小从 4MB 到 32MB 不等（最大 256Mbit = 32MB）
- **游戏丰富**：口袋妖怪、塞尔达、马里奥、火焰纹章等大量经典系列
- **模拟器成熟**：GBA 模拟器非常成熟，各平台都有优秀的模拟器
- **汉化游戏多**：GBA 时代是国内汉化组的黄金时期，大量游戏被翻译成中文

## 2. 适用场景

- **玩 GBA 游戏**：在电脑、手机、掌机上玩 GBA 经典游戏
- **怀旧体验**：重温 GBA 时代的经典游戏
- **游戏收藏**：收藏 GBA 游戏 ROM
- **ROM Hack**：修改 GBA 游戏（改版、汉化、自制游戏）
- **跨平台游玩**：在现代设备上随时随地玩 GBA 游戏
- **游戏开发**：学习 GBA 游戏开发（C 语言或汇编）

## 4. 如何编辑、如何导出

### 如何在电脑上玩 GBA 游戏

**使用 VisualBoyAdvance-M（最经典）：**
1. 下载 VBA-M
2. 解压并打开 VisualBoyAdvance-M.exe
3. 文件 → 打开 → 选择 .gba 文件
4. 开始游戏

**设置按键：**
1. 选项 → 输入 → 配置 → 1
2. 点击每个按键，然后按对应的键盘/手柄按键
3. 点击确定保存

**即时存档/读档：**
- 存档：`Shift + F1` ~ `Shift + F10`（10个存档位）
- 读档：`F1` ~ `F10`
- 加速：空格键
- 截图：F12

### GBA ROM 文件的基本知识

**ROM 大小：**
- 常见大小：4MB（32Mbit）、8MB（64Mbit）、16MB（128Mbit）、32MB（256Mbit）
- 早期游戏较小（4-8MB），后期游戏较大（16-32MB）
- 口袋妖怪系列通常是 16MB 或 32MB

**GBA 文件格式：**
- **.gba**：最常见的格式，纯 ROM 数据
- **.gb / .gbc**：Game Boy / Game Boy Color 格式（GBA 也能兼容）
- **.sav**：存档文件（通常和 ROM 同名，放在同目录）
- **.ips / .ups**：补丁文件（用于打汉化或改版补丁）

### GBA 存档类型

GBA 游戏有多种存档方式，模拟器需要正确识别：
- **SRAM**：32KB 静态内存存档（早期游戏常用）
- **EEPROM**：电可擦除只读存储器（分 4Kbit 和 64Kbit）
- **Flash**：闪存存档（分 64KB 和 128KB）
- **无存档**：部分游戏没有存档功能

现在的模拟器通常能自动识别存档类型，不需要手动设置。

### 如何给 ROM 打补丁（汉化/改版）

很多汉化版和改版是以补丁形式发布的（.ips 或 .ups 格式）：

**使用 Lunar IPS（打 IPS 补丁）：**
1. 下载 Lunar IPS
2. 打开 Lunar IPS
3. 点击 "Apply IPS Patch"
4. 选择补丁文件（.ips）
5. 选择原始 ROM 文件（.gba）
6. 自动生成打了补丁的新 ROM

**使用 UPS 补丁：**
1. 下载 NUPS（打 UPS 补丁的工具）
2. 打开 NUPS
3. 选择 "Apply a UPS patch to a file"
4. 选择 ROM 文件和 UPS 文件
5. 点击完成

**注意：**
- 打补丁前务必备份原始 ROM
- 确保补丁和 ROM 版本对应（日版/美版/欧版）
- 打好补丁的 ROM 就是汉化/改版了，可以直接用模拟器运行

## 5. 常见报错与解决

### 问题 1：GBA 游戏白屏、黑屏或花屏

**原因：** ROM 文件损坏、模拟器问题、或存档类型设置不对。

**解决方法：**
1. 换一个模拟器试试（mGBA 兼容性通常最好）
2. 重新下载 ROM 文件
3. 检查模拟器的存档类型设置（选项 → 模拟器 → 存档类型）
4. 尝试删除 .sav 存档文件（可能是存档损坏导致无法进入）
5. 更新模拟器到最新版本

### 问题 2：汉化版游戏玩不了或乱码

**原因：** 汉化补丁没打好，或用错了版本的 ROM。

**解决方法：**
1. 确认你有正确的原始 ROM（汉化补丁通常需要对应版本的原版 ROM）
2. 重新打补丁，严格按照汉化组的说明操作
3. 确认补丁是 IPS 还是 UPS 格式，用对应的工具
4. 直接下载已经打好补丁的汉化版 ROM（更简单）
5. 检查 ROM 和补丁的版本是否匹配（日版/美版/欧版）

### 问题 3：游戏存档丢失，下次打开要重新开始

**原因：** 模拟器没有正确保存存档，或存档路径有问题。

**解决方法：**
1. 确认模拟器设置中启用了自动存档
2. 检查存档文件（.sav）是否生成在 ROM 同目录
3. 确保模拟器有写入权限（不要放在 Program Files 等系统目录）
4. 使用即时存档更保险（Shift+F1 存档，F1 读档）
5. 有些游戏需要在游戏内正常存档才算数，模拟器的 SRAM 才会写入

### 问题 4：手机上玩 GBA 游戏卡顿

**原因：** 手机性能不足，或模拟器设置太高。

**解决方法：**
1. 降低渲染分辨率
2. 关闭一些特效（如滤镜、抗锯齿）
3. 关闭声音（如果不介意的话）
4. 换一个更轻量的模拟器
5. 关闭手机上其他后台应用
6. 现在的手机性能其实都足够流畅运行 GBA，卡顿通常是设置问题

## 💡 小知识

Game Boy Advance 是任天堂在 2001 年推出的 32 位掌机，也是 Game Boy 系列的第三代产品。它的横版设计、明亮的彩色屏幕（后来的 SP 版还有背光）、强大的游戏阵容，让它成为了无数人的童年回忆。

GBA 的游戏容量从最早的 4MB 到后期的 32MB，看起来不大，但在当时已经可以做出非常精致的游戏了。口袋妖怪、塞尔达传说 缩小帽、火焰纹章、黄金太阳、高级战争……这些经典游戏的名字，至今仍被玩家津津乐道。

GBA 模拟器的发展也非常迅速。早在 GBA 刚发售不久，就有程序员开始研究 GBA 的架构并开发模拟器。VisualBoyAdvance（VBA）是其中最著名的一个，它几乎成了 GBA 模拟器的代名词。后来 VBA 停止更新后，社区接手开发了 VBA-M（M 代表 Merge，合并了多个分支的改进）。而 mGBA 则是近年来崛起的新星，精度更高、功能更强。

GBA 时代也是国内游戏汉化组的黄金时期。因为 GBA 游戏大多没有中文版，而掌机游戏又特别需要看懂剧情，所以一大批汉化组应运而生——口袋群星、火花天龙剑、狼组、CGP、星组……他们用爱发电，把一款款经典游戏翻译成了中文，让无数中国玩家体验到了 GBA 游戏的魅力。很多人接触汉化游戏，就是从 GBA 时代开始的。
