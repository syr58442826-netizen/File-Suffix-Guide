# .7z 文件后缀详解

## 1. 文件定义 & 用途

7z 是 7-Zip 软件使用的压缩格式，是一种开源免费的高压缩率格式。它使用 LZMA 和 LZMA2 压缩算法，压缩率通常比 ZIP 和 RAR 更高，而且完全免费、没有专利限制。

7z 格式的核心特点：
- **压缩率最高**：主流格式中压缩率最高的之一
- **开源免费**：完全开源，没有专利费，任何人都可以免费使用
- **支持大文件**：支持最大 16EB（约 160 亿 GB）的超大文件
- **支持加密**：AES-256 强加密，还支持文件名加密
- **支持多种算法**：LZMA2、LZMA、PPMd、BZip2、Deflate 等
- **支持多线程**：充分利用多核 CPU，压缩速度快

## 2. 适用场景

- **高压缩需求**：追求最小体积的压缩场景
- **大文件压缩**：压缩超大文件（几十个 GB 以上）
- **数据备份**：备份数据时节省存储空间
- **软件分发**：很多开源软件使用 7z 格式发布
- **游戏资源打包**：游戏模组、素材包常用 7z
- **跨平台使用**：Windows/Mac/Linux 都有免费的解压工具

## 4. 如何编辑、如何导出

### 如何创建 7z 压缩包

**使用 7-Zip（Windows）：**
1. 选中要压缩的文件或文件夹
2. 右键 → 7-Zip → 添加到压缩包
3. 压缩格式选择 7z
4. 压缩等级选择（0 存储 ~ 9 极限压缩）
   - 等级越高，压缩率越高，但速度越慢
   - 日常使用推荐 5（标准）或 7（最大）
5. （可选）设置密码，勾选"加密文件名"更安全
6. （可选）设置分卷大小
7. 点击确定开始压缩

**使用 Keka（Mac）：**
1. 打开 Keka 应用
2. 选择 7z 格式
3. 把要压缩的文件拖进 Keka 窗口
4. 自动开始压缩

### 如何解压 7z 文件

**Windows：**
1. 安装 7-Zip 后，右键 → 7-Zip → 提取到当前位置
2. 或使用 Bandizip、PeaZip 等工具

**Mac：**
1. 安装 Keka 或 The Unarchiver
2. 双击 7z 文件自动解压

**Linux：**
```bash
# 安装 p7zip
sudo apt install p7zip-full   # Debian/Ubuntu
sudo dnf install p7zip        # Fedora

# 解压
7z x filename.7z
```

### 如何编辑 7z 内容

- 7-Zip 可以直接在压缩包中添加、删除、重命名文件
- 打开 7-Zip 文件管理器，双击进入压缩包
- 就像操作普通文件夹一样操作压缩包内的文件
- 修改后自动保存

## 5. 常见报错与解决

### 问题 1：7z 文件损坏，无法解压

**原因：** 下载不完整、传输错误或存储介质损坏。

**解决方法：**
1. 重新下载文件
2. 用 7-Zip 打开后，点击"测试"按钮检查完整性
3. 如果是分卷压缩，确认所有分卷都齐全
4. 使用 7-Zip 的"修复"功能（工具 → 修复压缩文件）
5. 注意：7z 的修复能力有限，不如 RAR 的恢复记录强大

### 问题 2：7z 解压速度特别慢

**原因：** 7z 压缩率高，解压也需要更多计算资源；或者电脑配置较低。

**解决方法：**
1. 耐心等待，高压缩率的文件解压本来就慢
2. 关闭其他占用 CPU 的程序
3. 如果是自己压缩的，下次压缩时选择较低的压缩等级
4. 解压到 SSD 比 HDD 快很多
5. 确认不是硬盘读写速度瓶颈

### 问题 3：解压后文件名乱码

**原因：** 压缩和解压使用的编码不同。

**解决方法：**
1. 使用 7-Zip 解压，在提取对话框中选择正确的代码页
2. 使用 Bandizip 解压（自动检测编码能力强）
3. Mac 用户用 Keka，设置中调整编码
4. 压缩时建议使用 UTF-8 编码（7-Zip 默认就是 UTF-8）
5. 避免使用特殊字符和 emoji 作为文件名

### 问题 4：7z 加密压缩后，密码正确但打不开

**原因：** 可能是密码输入错误（大小写、特殊字符），或文件损坏。

**解决方法：**
1. 仔细检查密码，注意大小写和中英文标点
2. 用记事本输入密码再复制粘贴，避免输入法问题
3. 确认文件没有损坏（用测试功能检查）
4. 如果是从别人那里收到的文件，确认密码是否正确
5. 7z 的 AES-256 加密非常安全，忘记密码几乎无法破解

### 问题 5：7-Zip 右键菜单不见了

**原因：** 软件升级、系统更新或其他软件冲突导致右键菜单丢失。

**解决方法：**
1. 打开 7-Zip 文件管理器（7zFM.exe）
2. 工具 → 选项 → 7-Zip
3. 勾选"集成 7-Zip 到右键菜单"
4. 点击应用确定
5. 如果还不行，重新安装 7-Zip

## 💡 小知识

7-Zip 是由俄罗斯程序员 Igor Pavlov 开发的，它的名字来源于"7-Zip"，而 7z 格式的名字也由此而来。最有趣的是，7-Zip 本身是完全免费开源的，但它的开发者却非常低调——你几乎找不到关于他的采访或照片。

7z 格式的压缩率到底有多高呢？举个例子：同样的一堆文档，ZIP 压缩后是 100MB，RAR 可能是 85MB，而 7z（最高压缩等级）可能只有 70MB 甚至更小。对于文本、代码、文档类文件，7z 的优势尤其明显。

另外，7z 格式还有一个很酷的功能——自解压文件（SFX）。你可以把 7z 压缩包做成一个 .exe 文件，对方电脑上即使没有安装 7-Zip，双击也能自动解压。
