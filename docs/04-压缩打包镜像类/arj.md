# .arj 文件后缀详解

## 1. 文件定义 & 用途

ARJ（Archived by Robert Jung）是一种古老的压缩文件格式，由奥地利程序员 Robert K. Jung 在 1990 年代初开发。在 DOS 和 Windows 3.x 时代，ARJ 曾经是非常流行的压缩格式之一，与 PKZIP（ZIP 格式）、LZH 等齐名。它以其出色的压缩率和丰富的功能（如分卷压缩、多卷归档、自解压等）而闻名。

ARJ 格式的核心特点：
- **年代久远**：DOS 时代的老牌压缩格式，1990 年代初非常流行
- **压缩率高**：在当年的压缩格式中，ARJ 的压缩率属于第一梯队
- **功能丰富**：支持分卷压缩、自解压、注释、密码保护等
- **DOS 风格命令行**：ARJ 软件是命令行工具，参数众多
- **已被淘汰**：随着 ZIP 和 RAR 的普及，ARJ 逐渐退出主流
- **考古价值**：现在只能在一些老软件、老游戏、BBS 资源中见到

## 2. 适用场景

- **老软件/老游戏解压**：DOS 时代的老软件、老游戏很多用 ARJ 打包
- **BBS 资源考古**：早年拨号 BBS 上的资源常用 ARJ 格式
- **复古计算机爱好**：研究 DOS 时代的软件和文件格式
- **旧档案处理**：处理 90 年代的旧数据备份、旧光盘中的 ARJ 文件
- **格式历史研究**：了解压缩格式的发展历程

## 3. 推荐打开软件

| 平台 | 免费软件 | 专业软件 |
|------|----------|----------|
| Windows | 7-Zip、WinRAR（支持解压）、PeaZip、Bandizip | - |
| Mac | Keka、The Unarchiver、unar（命令行） | - |
| Linux | arj（命令行工具）、7-Zip（p7zip）、File Roller | - |

**新手推荐：** Windows 上直接用 7-Zip 或 WinRAR 即可解压绝大多数 ARJ 文件。

## 4. 如何编辑、如何导出

### 如何解压 ARJ 文件

**使用 7-Zip（Windows，最简单）：**
1. 安装 7-Zip
2. 右键 ARJ 文件 → 7-Zip → 提取到当前位置
3. 或直接双击打开（7-Zip 会关联 .arj 格式）

**使用 WinRAR：**
1. WinRAR 原生支持 ARJ 解压
2. 双击 ARJ 文件即可在 WinRAR 中查看内容
3. 点击"解压到"按钮选择输出路径

**使用命令行（Linux）：**
```bash
# 安装 arj 工具
sudo apt install arj    # Debian/Ubuntu
sudo dnf install arj    # Fedora

# 解压
arj x filename.arj

# 查看内容（不解压）
arj l filename.arj
```

### 能否创建 ARJ 文件？

- **现代基本不再使用**：ARJ 格式已经过时，不建议创建新的 ARJ 文件
- **如果必须创建**：
  - Windows：可以下载老版本的 ARJ for DOS，在 DOSBox 中运行
  - Linux：使用 `arj a output.arj files...` 命令
- **现代替代方案**：推荐使用 ZIP（兼容性最好）或 7z（压缩率最高）

### 分卷 ARJ 的解压

ARJ 格式很早就支持分卷压缩，分卷文件通常命名为：
- `.arj`（第一卷）
- `.a01`、`.a02`...（后续分卷）

解压方法：
1. 确保所有分卷文件在同一个文件夹
2. 用 7-Zip 或 WinRAR 打开第一个 .arj 文件
3. 正常解压即可，软件会自动读取后续分卷

## 5. 常见报错与解决

### 问题 1：ARJ 文件无法解压，提示"不支持的格式"或损坏

**原因：** 可能是文件损坏、分卷不完整，或使用了特殊版本的 ARJ 压缩。

**解决方法：**
1. 确认文件是否完整（尤其是分卷文件，检查所有分卷是否齐全）
2. 尝试用不同的软件解压：先试 7-Zip，再试 WinRAR
3. 如果是从网上下载的，重新下载一次
4. 用 ARJ 命令行工具尝试修复：`arj r filename.arj`

### 问题 2：解压后文件名乱码

**原因：** ARJ 是 DOS 时代的格式，使用的是 DOS 编码（如 GBK、CP437），现代系统解码不匹配。

**解决方法：**
1. 使用 7-Zip 解压，在提取对话框中尝试不同的代码页
2. 使用 Bandizip 解压（自动检测编码能力较强）
3. 解压后用批量重命名工具修正文件名
4. 如果是日文/韩文资源，对应设置正确的编码

### 问题 3：不知道这是什么格式，以为是压缩包但打不开

**原因：** ARJ 格式现在很少见，很多人不认识。

**解决方法：**
1. 安装 7-Zip，它几乎支持所有古老的压缩格式
2. 右键 → 7-Zip → 打开压缩包，看看能否识别
3. 如果 7-Zip 也打不开，可能不是 ARJ 文件，只是后缀相同
4. 用十六进制编辑器查看文件头，ARJ 文件头通常以 `60 EA` 开头

## 💡 小知识

ARJ 的名字来源于它的作者 Robert K. Jung 的首字母缩写——Archived by Robert Jung。在 1990 年代初的 DOS 世界里，ARJ 是一个非常"硬核"的压缩工具。它完全是命令行操作，参数多到让人眼花缭乱，但功能也非常强大——分卷压缩、自解压、文件注释、密码保护、甚至可以在压缩包里存多个版本的文件。

当年在 BBS（电子公告板系统）上，ARJ 格式非常流行。因为拨号上网速度慢，大家都追求最高的压缩率，而 ARJ 的压缩率确实比当时的 PKZIP 还要好一些。很多老游戏、老软件的破解版都是用 ARJ 打包的。

不过 ARJ 最终还是败给了 ZIP 和 RAR。原因有几个：一是 PKZIP/WinZip 的图形界面对新手更友好；二是 RAR 的压缩率后来居上；三是 ARJ 的作者后来停止了积极开发。现在 ARJ 已经成了压缩格式界的"活化石"，只能在考古的时候才会遇到。
