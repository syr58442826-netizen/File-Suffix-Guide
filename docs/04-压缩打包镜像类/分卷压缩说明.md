# 分卷压缩说明

## 什么是分卷压缩？

分卷压缩（也叫多卷压缩）是把一个大文件或文件夹压缩后，分割成多个大小相等的小文件（称为"分卷"）。这样做的目的是为了方便传输和存储大文件。

例如：你有一个 5GB 的视频文件，想传到网盘上，但网盘单文件限制是 2GB。这时候就可以用分卷压缩，把它分成 3 个 2GB 以下的分卷文件，分别上传。下载后放在一起解压，就能得到完整的原文件。

## 为什么需要分卷压缩？

### 常见使用场景

1. **网盘上传限制**：很多网盘对单文件大小有限制（如 2GB、4GB、10GB）
2. **邮件附件限制**：邮箱附件通常只有几十 MB 的限制
3. **U盘/光盘存储**：FAT32 格式的 U 盘单文件不能超过 4GB
4. **方便传输**：大文件传输中断后，只需重传失败的分卷
5. **论坛/社区分享**：早年论坛附件大小有限制，分卷是必备技能
6. **刻录光盘**：把大文件分成光盘容量大小的分卷，刻到多张光盘上

## 分卷压缩的命名规则

不同的压缩格式，分卷文件的命名方式不同：

### RAR 分卷
- **旧版 RAR**：`filename.part1.rar`、`filename.part2.rar`、`filename.part3.rar`...
- **更早的命名**：`filename.rar`、`filename.r00`、`filename.r01`...
- 解压时从第一个分卷（.part1.rar 或 .rar）开始

### 7z 分卷
- 命名方式：`filename.7z.001`、`filename.7z.002`、`filename.7z.003`...
- 解压时从 .001 文件开始

### ZIP 分卷
- 命名方式：`filename.zip`、`filename.z01`、`filename.z02`...
- 或者：`filename.part1.zip`、`filename.part2.zip`...（取决于软件）
- 注意：不同软件的 ZIP 分卷格式可能不兼容

### tar 分卷（Linux）
- 用 split 命令分割：`filename.tar.gz.aa`、`filename.tar.gz.ab`...
- 解压时需要先合并再解压

## 如何创建分卷压缩

### 方法一：使用 WinRAR（推荐，分卷功能最成熟）

1. 选中要压缩的文件或文件夹
2. 右键 → WinRAR → 添加到压缩文件
3. 压缩格式选择 RAR 或 RAR5
4. 在"压缩分卷大小"处输入分卷大小
   - 可以直接输入数值和单位，如 `100MB`、`2GB`
   - 也可以从下拉菜单选择预设大小（CD 700MB、DVD 4.7GB 等）
5. （可选）设置密码、添加恢复记录
6. 点击确定开始压缩

### 方法二：使用 7-Zip（免费）

1. 选中要压缩的文件
2. 右键 → 7-Zip → 添加到压缩包
3. 压缩格式选择 7z 或 zip
4. 在"分卷大小"处输入大小，如 `500m`
5. 点击确定开始压缩

### 方法三：使用 Bandizip（免费，界面友好）

1. 打开 Bandizip
2. 点击"新建压缩"，添加文件
3. 选择压缩格式
4. 勾选"分割压缩包"，输入分卷大小
5. 点击"开始压缩"

### 方法四：Linux 命令行

```bash
# 使用 tar + split 分割
tar -czvf - /path/to/files | split -b 100M - output.tar.gz.

# 上面的命令会生成：
# output.tar.gz.aa
# output.tar.gz.ab
# output.tar.gz.ac
# ...

# 使用 7z 分卷
7z a -v100m output.7z /path/to/files/

# 使用 rar 分卷（需要安装 rar）
rar a -v100M output.rar /path/to/files/
```

## 如何解压分卷压缩

### 基本步骤

1. **确保所有分卷都下载完整**
   - 检查分卷数量是否正确
   - 所有分卷大小是否合理（最后一个可能较小，其他应该相等）
   - 所有分卷放在**同一个文件夹**里

2. **只解压第一个分卷**
   - RAR 分卷：双击 `filename.part1.rar` 或 `filename.rar`
   - 7z 分卷：双击 `filename.7z.001`
   - ZIP 分卷：双击 `filename.zip` 或 `filename.part1.zip`

3. **软件会自动按顺序读取所有分卷**
   - 不要手动一个个解压
   - 如果缺少分卷，解压会在对应位置失败

### Windows 下解压

**使用 WinRAR / 7-Zip / Bandizip：**
1. 确认所有分卷在同一文件夹
2. 右键点击第一个分卷
3. 选择"解压到当前文件夹"或"解压到 xxx\"
4. 等待解压完成

### Mac 下解压

**使用 The Unarchiver / Keka：**
1. 确认所有分卷在同一文件夹
2. 双击第一个分卷
3. 自动解压

### Linux 下解压

```bash
# 7z 分卷
7z x filename.7z.001

# RAR 分卷
unrar x filename.part1.rar

# tar.gz 分卷（用 split 分割的）
cat filename.tar.gz.* | tar -xzv

# 或者先合并再解压
cat filename.tar.gz.aa filename.tar.gz.ab filename.tar.gz.ac > filename.tar.gz
tar -xzvf filename.tar.gz
```

## 分卷压缩的常见问题

### 问题 1：解压时提示"找不到下一个分卷"怎么办？

**原因：** 缺少某个分卷，或分卷文件名不对。

**解决方法：**
1. 检查是不是所有分卷都下载了
2. 确保所有分卷在同一个文件夹里
3. 检查分卷文件名是否一致（有些下载工具会自动改名）
4. 分卷文件名必须连续，不能缺少中间某一个
5. 如果确实缺少分卷，只能回去重新下载缺失的那个

### 问题 2：分卷可以单独解压吗？

**回答：** 不行。分卷压缩是把一个完整的文件切开的，缺少任何一部分都无法完整解压。

补充说明：
- 对于文本文件，有时可以解压出部分内容（但会有损坏）
- 对于视频文件，有时可以播放一部分（但会有花屏或中断）
- 对于程序或压缩包，缺少任何一部分都无法正常使用

### 问题 3：分卷大小设多少合适？

**建议：**
- **网盘上传**：根据网盘限制来，如 2GB、4GB、10GB
- **邮件发送**：10MB-25MB（根据邮箱限制）
- **U盘存储**：FAT32 格式设为 4GB 以下，NTFS 不用分卷
- **刻录光盘**：CD 设为 700MB，DVD 设为 4.7GB
- **一般分享**：100MB-500MB 比较合适，下载失败了重传成本低

### 问题 4：分卷压缩的解压速度比单文件慢吗？

**回答：** 基本差不多。分卷只是把文件切开了，解压时软件会自动按顺序读取，不会因为分卷而明显变慢。

唯一可能慢一点的地方是：如果分卷很多，硬盘需要频繁切换文件，可能有轻微的性能损失，但一般感觉不到。

### 问题 5：如何验证分卷是否完整？

**方法：**
1. **WinRAR**：打开第一个分卷，点击"测试"按钮
2. **7-Zip**：右键第一个分卷 → 7-Zip → 测试压缩包
3. **Linux**：
   ```bash
   # 测试 7z 分卷
   7z t filename.7z.001
   
   # 测试 rar 分卷
   unrar t filename.part1.rar
   ```
4. 如果测试通过，说明所有分卷都是完整的

### 问题 6：分卷的顺序乱了会怎样？

**回答：** 只要文件名是正确的（part1、part2... 或 001、002...），软件会自动按文件名排序，不影响解压。

但如果文件名被改了，导致顺序错乱，解压就会失败。所以不要随意修改分卷的文件名。

### 问题 7：可以把分卷合并成一个压缩包吗？

**可以：**
- **RAR 分卷**：用 WinRAR 打开，直接解压，然后重新压缩成单文件
- **7z 分卷**：用 7-Zip 解压后重新压缩
- **tar 分卷**：用 cat 命令合并
  ```bash
  cat file.tar.gz.* > file.tar.gz
  ```

一般不建议合并，直接解压就行了。合并只是为了方便管理。

## 分卷压缩小技巧

### 技巧 1：添加恢复记录（RAR 特有）

对于重要文件，压缩时可以添加恢复记录（Recovery Record），比例建议 1%-5%。这样即使某个分卷有轻微损坏，也有机会修复。

WinRAR 操作：添加到压缩文件 → 高级 → 恢复记录 → 设置百分比

### 技巧 2：分卷文件名规范

- 所有分卷放在一个专门的文件夹里
- 文件名要清晰，包含内容说明和分卷信息
- 例如：`2024年度备份.part1.rar`、`2024年度备份.part2.rar`

### 技巧 3：上传前先测试

分卷上传到网盘前，先用压缩软件测试一下完整性，确认没有问题再上传。避免下载下来才发现文件坏了。

### 技巧 4：大文件优先用 RAR 分卷

RAR 的分卷功能最成熟，支持恢复记录，容错性最好。重要文件的分卷压缩推荐用 RAR 格式。
