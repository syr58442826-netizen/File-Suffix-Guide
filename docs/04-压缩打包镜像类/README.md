# 压缩打包镜像类文件后缀大全

本分类收录了常见的压缩、打包和镜像文件格式，帮助你了解各种压缩格式的特点和使用方法。

## 分类简介

压缩文件是我们日常工作中经常接触的文件类型。无论是发送邮件、下载资源、备份数据，还是传输大文件，压缩工具都能帮我们节省空间和时间。不同的压缩格式有不同的特点——有的压缩率高，有的速度快，有的支持分卷，有的兼容性好。

了解这些格式的区别，可以帮助你在不同场景下选择最合适的压缩方式。

## 压缩格式

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.zip](./zip.md) | ZIP 压缩 | 最通用的压缩格式，所有系统都支持 |
| [.rar](./rar.md) | RAR 压缩 | 压缩率高，支持分卷和恢复记录 |
| [.7z](./7z.md) | 7-Zip 压缩 | 开源免费，压缩率最高 |
| [.tar](./tar.md) | TAR 打包 | Linux/Unix 打包格式，只打包不压缩 |
| [.gz](./gz.md) | GZIP 压缩 | Linux 常用压缩格式，常和 tar 搭配 |
| [.bz2](./bz2.md) | BZIP2 压缩 | 压缩率比 gz 高，但速度较慢 |
| [.xz](./xz.md) | XZ 压缩 | 基于 LZMA2 算法，压缩率极高 |
| [.zst](./zst.md) | Zstandard 压缩 | Facebook 开源，压缩快且压缩率高 |
| [.cab](./cab.md) | Windows 柜文件 | 微软安装包压缩格式 |

## 快速选择指南

- **日常使用（Windows）**：ZIP 格式兼容性最好，系统自带就能打开
- **追求高压缩率**：7z 或 xz 格式压缩率最高，而且完全免费
- **追求压缩速度**：zst（Zstandard）压缩速度快且压缩率高，是现代新选择
- **分卷压缩/恢复记录**：RAR 格式最成熟，适合传输大文件
- **Linux 环境**：tar.gz 是标准组合，几乎所有发行版都支持；tar.xz 压缩率更高
- **Windows 安装包**：CAB 格式是微软系统组件和驱动包的专用压缩格式
- **备份系统/光盘**：ISO 镜像可以完整保存光盘内容
- **跨平台传输**：优先选 ZIP，其次是 7z
