# 数据配置日志类

在数据处理、程序开发和系统运维中，有一类文件承担着「数据存储、程序配置、运行记录」的重要角色。它们不像办公文档那样用来展示给人看，而是更多地被程序读取和处理。理解这些文件的特点，对数据分析师、开发人员和运维工程师都非常重要。

## 分类简介

本分类收录了在数据处理、程序配置和系统运维中常见的文件后缀，包括：

- **数据表格类**：CSV、XLS（从数据处理和程序交互视角）
- **配置文件类**：INI、CONFIG、ENV
- **日志记录类**：LOG（从程序运行和调试视角）
- **临时缓存类**：TMP、CACHE

> 注意：CSV、XLS、INI、LOG 等后缀在「日常办公文档类」或「编程源代码文件」分类中也有介绍，但侧重点不同。本分类从**数据处理和程序配置**的角度出发，更关注如何用程序读写、如何用于系统配置、如何进行数据分析等内容。

## 后缀列表

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.csv](./csv.md) | 逗号分隔值文件 | 纯文本表格格式，数据交换的通用语言 |
| [.xls](./xls.md) | Excel 二进制表格 | 传统 Excel 格式，数据处理中的历史格式 |
| [.ini](./ini.md) | 初始化配置文件 | 经典的节-键值对配置格式 |
| [.config](./config.md) | 配置文件 | 通用配置文件，格式多样 |
| [.env](./env.md) | 环境变量文件 | 存储环境变量，常用于项目配置 |
| [.log](./log.md) | 日志文件 | 记录程序运行状态和错误信息 |
| [.tmp](./tmp.md) | 临时文件 | 程序运行过程中产生的临时数据 |
| [.cache](./cache.md) | 缓存文件 | 用于加速访问的缓存数据 |

## 使用建议

- **数据交换**：CSV 是首选，兼容性最好，几乎所有语言和工具都支持
- **程序配置**：简单场景用 INI，环境变量用 .env，复杂配置用 YAML/JSON
- **日志排查**：掌握 LOG 文件的分析方法，是调试程序的必备技能
- **临时文件**：TMP 和 CACHE 文件可以安全删除，但要注意不要误删正在使用的文件
