# .srt 文件后缀详解

## 1. 文件定义 & 用途

SRT（全称 SubRip Text）是最流行、最简单的字幕文件格式。它是一种纯文本格式，记录了每一条字幕的开始时间、结束时间和字幕内容。

SRT 格式的核心特点：
- **纯文本格式**：用记事本就能打开和编辑
- **结构简单**：序号 + 时间轴 + 字幕内容，一目了然
- **兼容性最好**：几乎所有播放器和视频网站都支持
- **不支持样式**：字体、颜色、大小由播放器决定
- **体积小巧**：一部电影的字幕通常只有几十 KB

## 2. 适用场景

- **外挂字幕**：最常用的外挂字幕格式
- **视频网站上传**：B站、YouTube 等平台都支持 SRT 字幕
- **视频剪辑**：剪映、Premiere 等软件支持导入 SRT
- **字幕制作**：新手制作字幕的入门格式
- **外语学习**：配合播放器看双语电影
- **视频加字幕**：给视频批量添加字幕

## 4. 如何编辑、如何导出

### SRT 文件格式示例

```
1
00:00:01,000 --> 00:00:04,000
大家好，欢迎来到今天的节目

2
00:00:05,000 --> 00:00:08,500
今天我们来聊聊 SRT 字幕格式
```

格式说明：
1. 序号（从 1 开始递增）
2. 时间轴（格式：时:分:秒,毫秒 --> 时:分:秒,毫秒）
3. 字幕内容（可以一行或多行）
4. 空行分隔下一条字幕

### 如何编辑

**简单编辑（修改文字/时间）：**
- 用记事本或 Notepad++ 直接打开修改
- 注意保持时间格式正确
- 保存时选择 UTF-8 编码，避免乱码

**专业字幕制作：**
- 使用 Subtitle Edit（免费开源，功能强大，推荐新手）
- 使用 Aegisub（功能更强大，适合专业字幕组）
- 使用剪映的自动生成字幕后导出 SRT

### 如何导出

**从视频自动生成 SRT：**
1. 使用剪映（免费，导入视频→自动识别字幕→导出字幕）
2. 使用网易见外工作台（在线语音转写，支持导出 SRT）
3. 使用 Subtitle Edit 的语音识别功能

**从其他字幕格式转 SRT：**
1. 用 Subtitle Edit 打开原字幕文件
2. 选择"文件" → "另存为"
3. 格式选择 SubRip（.srt）
4. 选择编码（推荐 UTF-8）
5. 保存即可

**给视频嵌入 SRT 字幕：**
1. 用格式工厂或 HandBrake，添加字幕后转码
2. 用 MKVToolNix 把 SRT 封装进 MKV 文件
3. 用剪映导入 SRT 字幕后导出视频

## 5. 常见报错与解决

### 问题 1：SRT 字幕显示乱码

**原因：** 字幕文件编码和播放器不匹配。

**解决方法：**
1. 用记事本打开 SRT 文件，选择"另存为"，编码选 UTF-8
2. 在播放器设置中切换字幕编码（如 GBK/UTF-8/自动检测）
3. 使用 VLC 播放器，自动识别能力更强
4. 用 Subtitle Edit 打开后重新保存为 UTF-8 编码

### 问题 2：字幕和声音对不上（字幕太快或太慢）

**原因：** 字幕文件和视频版本不匹配（不同版本的视频时长有差异）。

**解决方法：**
1. 在播放器中调整字幕延迟（VLC 按 G 和 H 键微调）
2. 用 Subtitle Edit 打开字幕，使用"时间偏移"功能整体调整
3. 重新下载和视频版本匹配的字幕
4. 如果整体速度不对，用"缩放时间轴"功能调整

### 问题 3：视频播放器不显示字幕

**原因：** 字幕文件名和视频名不一致，或播放器设置问题。

**解决方法：**
1. 确保字幕文件名和视频文件名完全一样（除了后缀）
   - 例如：`电影.mp4` 和 `电影.srt` 放在同一个文件夹
2. 检查播放器是否开启了字幕显示
3. 手动在播放器中加载字幕文件（拖入播放器或右键选择字幕）
4. 确认 SRT 文件格式正确（可以用 Subtitle Edit 检查）

### 问题 4：SRT 字幕导入剪辑软件失败

**原因：** 时间格式不对或文件编码有问题。

**解决方法：**
1. 检查时间轴格式是否正确（必须是 `HH:MM:SS,mmm` 格式，逗号是英文逗号）
2. 确认文件是纯文本格式（不是 Word 文档或 RTF）
3. 用 Subtitle Edit 打开后重新保存
4. 检查字幕序号是否连续、有无重复
5. 转成 UTF-8 编码后再试试

## 💡 小知识

SRT 格式的全称是 SubRip Text，它来源于一个叫 SubRip 的软件。这个软件可以从 DVD 中"提取"字幕——它会分析 DVD 视频画面中的字幕区域，用 OCR 技术把字幕文字识别出来，并记录下每条字幕出现的时间。

SRT 格式之所以能成为最流行的字幕格式，秘诀就在于"简单"。它的格式太简单了，任何人用记事本都能写，任何播放器都能轻松解析。这种极简设计反而让它成为了字幕界的"通用语"。
