# 音视频媒体类文件后缀大全

本分类收录了常见的音视频文件格式、字幕格式，帮助你快速了解各种媒体文件的特点、用途和处理方法。

## 分类简介

音视频媒体文件是我们日常接触最多的文件类型之一，涵盖了电影、音乐、短视频、网课等多种内容。不同的格式有不同的特点——有的体积小适合网络传播，有的画质高适合专业剪辑，有的音质好适合音乐收藏。

了解这些格式的区别，可以帮助你在下载、转换、剪辑时做出正确的选择。

## 视频格式

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.mp4](./mp4.md) | MP4 视频 | 最通用的视频格式，兼容性最好 |
| [.mkv](./mkv.md) | Matroska 视频 | 开源容器格式，支持多音轨多字幕 |
| [.avi](./avi.md) | AVI 视频 | 老牌视频格式，文件较大 |
| [.mov](./mov.md) | QuickTime 视频 | Apple 出品，常用于苹果设备和剪辑 |
| [.flv](./flv.md) | Flash 视频 | 早年网页视频主流格式，现已逐渐淘汰 |
| [.3gp](./3gp.md) | 3GP 视频 | 3G 时代手机视频格式，体积小画质低 |
| [.vob](./vob.md) | VOB 视频 | DVD 光盘视频格式，包含多音轨和字幕 |

## 音频格式

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.mp3](./mp3.md) | MP3 音频 | 最流行的有损音频格式，兼容性极强 |
| [.wav](./wav.md) | WAV 音频 | 无损未压缩格式，音质最好，体积大 |
| [.flac](./flac.md) | FLAC 音频 | 无损压缩格式，音乐发烧友首选 |
| [.m4a](./m4a.md) | M4A 音频 | AAC 编码格式，苹果设备常用 |
| [.aiff](./aiff.md) | AIFF 音频 | 苹果无损音频格式，与 WAV 同等音质 |

| 后缀 | 名称 | 简介 |
|------|------|------|
| [.srt](./srt.md) | SRT 字幕 | 最常用的纯文本字幕格式 |

| [.lrc](./lrc.md) | LRC 歌词 | 歌词字幕格式，逐行显示时间戳 |

## 快速选择指南

- **普通看视频**：选 MP4 就对了，所有设备都支持
- **下载电影/动漫**：MKV 通常带有多音轨和字幕
- **听音乐（普通音质）**：MP3 或 M4A，体积小兼容性好
- **听音乐（追求音质）**：FLAC 无损格式
- **做视频剪辑**：MOV 或 AVI，剪辑软件兼容性好
- **外挂字幕**：SRT 最简单，ASS 效果更丰富
- **流媒体直播**：M3U8 是 HLS 标准格式，几乎所有直播平台都在用
- **老视频翻录**：DVD 用 VOB，老手机视频用 3GP
- **苹果无损音频**：AIFF，或用 FLAC 体积更小
