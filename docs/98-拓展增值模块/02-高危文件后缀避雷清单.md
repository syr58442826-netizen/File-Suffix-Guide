# 02 - 高危文件后缀避雷清单

> 🔴 **红色警告**：本文列出的文件后缀都可能直接执行代码，遇到不认识的这类文件，**千万不要随便双击**！

---

## 一、什么是高危文件后缀？

### 1.1 定义

**高危文件后缀**，就是那些**能够直接执行代码或命令**的文件格式。

简单说就是：你双击它，它就会在你的电脑上"干活"——可能是安装软件，也可能是删除文件、偷取密码、加密你的数据（勒索病毒）。

### 1.2 为什么危险？

- **双击即运行**：不需要额外的软件，系统本身就能执行
- **威力巨大**：能做任何操作——删文件、偷数据、开后门、挖矿
- **难以察觉**：有些病毒运行后没有任何界面，偷偷在后台干活
- **伪装容易**：可以伪装成图片、文档等安全格式

### 1.3 安全等级说明

| 等级 | 含义 | 代表后缀 |
|------|------|---------|
| 🔴 极高危 | 双击直接运行，破坏力最大 | .exe、.bat、.vbs |
| 🟠 高危 | 需要特定条件触发，也很危险 | .docm、.xlsm（宏文件） |
| 🟡 中危 | 一般需要用户主动操作 | .html、.js（脚本文件） |
| 🟢 低危 | 本身不执行代码，基本安全 | .txt、.jpg、.pdf |

> 注意：低危不代表绝对安全。比如 PDF 也可能被植入恶意代码，图片也可能藏有病毒（通过漏洞），但相对来说风险小很多。

## 二、Windows 高危后缀 TOP10

以下是 Windows 平台上最常见、最危险的 10 种可执行文件后缀。

### TOP 1：.exe —— 可执行程序

| 项目 | 说明 |
|------|------|
| **全称** | Executable File |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 任何操作——安装软件、删除文件、偷密码、挖矿…… |
| **正常用途** | 安装程序、软件主程序、工具软件 |
| **危险之处** | 最常见的病毒载体，90% 以上的 Windows 病毒是 exe 格式 |

**注意**：不是所有 exe 都危险——你电脑上的 QQ、微信、浏览器都是 exe 文件。危险的是**来源不明**的 exe。

### TOP 2：.bat —— 批处理文件

| 项目 | 说明 |
|------|------|
| **全称** | Batch File |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 执行一系列 CMD 命令，可以格式化硬盘、删除文件、下载病毒 |
| **正常用途** | 批量执行系统命令、自动化脚本 |
| **危险之处** | 用记事本就能写，门槛极低；代码是明文的，但新手看不懂 |

### TOP 3：.cmd —— 命令脚本

| 项目 | 说明 |
|------|------|
| **全称** | Windows Command Script |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 和 .bat 基本一样，执行 CMD 命令 |
| **正常用途** | 系统管理脚本、自动化任务 |
| **危险之处** | 和 .bat 类似，但功能更多一些 |

### TOP 4：.vbs —— VBScript 脚本

| 项目 | 说明 |
|------|------|
| **全称** | VBScript Script File |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 调用系统功能、弹出窗口、操作文件、下载运行程序 |
| **正常用途** | 系统管理脚本、Office 宏（旧版） |
| **危险之处** | 经典病毒"爱虫（ILOVEYOU）"就是 vbs 格式；伪装成情书传播 |

**经典案例：ILOVEYOU 病毒**
- 2000 年爆发，感染了 4500 万台电脑
- 伪装成情书邮件，附件是 `LOVE-LETTER-FOR-YOU.TXT.vbs`
- 因为 Windows 默认隐藏后缀，受害者看到的是 `LOVE-LETTER-FOR-YOU.TXT`
- 以为是文本文件，双击后病毒开始传播
- 造成了约 100 亿美元的损失

### TOP 5：.js —— JScript 脚本

| 项目 | 说明 |
|------|------|
| **全称** | JScript File（注意：不是网页的 JavaScript） |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 和 VBScript 类似，能调用 Windows 系统功能 |
| **正常用途** | 系统脚本、自动化任务 |
| **危险之处** | 容易和网页的 .js 文件混淆；双击后用 Windows Script Host 执行 |

> **重要区分**：网页里的 JavaScript（.js 文件）是在浏览器沙箱里运行的，相对安全；但本地的 .js 文件如果双击用 WSH 执行，就有系统权限，非常危险。

### TOP 6：.wsf —— Windows 脚本文件

| 项目 | 说明 |
|------|------|
| **全称** | Windows Script File |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 可以混合 VBScript 和 JScript，功能强大 |
| **正常用途** | 复杂的系统管理脚本 |
| **危险之处** | 不太常见，但正因为少见，更容易让人掉以轻心 |

### TOP 7：.scr —— 屏幕保护程序

| 项目 | 说明 |
|------|------|
| **全称** | Screen Saver |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 本质上就是 exe 文件，能做任何事 |
| **正常用途** | 屏幕保护程序 |
| **危险之处** | 经常被用来伪装——"美女屏保.scr"其实是病毒 |

> **冷知识**：.scr 文件和 .exe 文件的格式完全一样，只是后缀不同。Windows 遇到 .scr 会直接当程序运行。

### TOP 8：.com —— DOS 命令文件

| 项目 | 说明 |
|------|------|
| **全称** | DOS Command File |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 和 exe 类似，直接执行机器码 |
| **正常用途** | 老 DOS 系统的命令文件 |
| **危险之处** | 现在已经很少见了，但病毒偶尔还会用 |

### TOP 9：.pif —— 程序信息文件

| 项目 | 说明 |
|------|------|
| **全称** | Program Information File |
| **危险等级** | 🔴 极高危 |
| **能做什么** | 指向 DOS 程序的快捷方式，运行时会执行目标程序 |
| **正常用途** | 老系统的 DOS 程序配置 |
| **危险之处** | 可以指向病毒程序；因为图标看起来像文档，容易被骗 |

### TOP 10：.msi —— Windows 安装包

| 项目 | 说明 |
|------|------|
| **全称** | Microsoft Installer |
| **危险等级** | 🟠 高危 |
| **能做什么** | 安装软件，过程中可以执行任意操作 |
| **正常用途** | 正规软件的安装包 |
| **危险之处** | 伪装成软件安装包的病毒很多；安装时会弹 UAC 提示，但很多人习惯点"是" |

### 高危后缀速查表

| 排名 | 后缀 | 类型 | 危险等级 | 一句话总结 |
|------|------|------|---------|-----------|
| 1 | .exe | 可执行程序 | 🔴 | 最常见，双击就运行 |
| 2 | .bat | 批处理 | 🔴 | 文本格式的命令集合 |
| 3 | .cmd | 命令脚本 | 🔴 | 比 bat 功能更强的批处理 |
| 4 | .vbs | VBScript | 🔴 | 经典病毒格式，爱虫病毒就是它 |
| 5 | .js | JScript | 🔴 | 别和网页 JS 搞混了 |
| 6 | .wsf | Windows脚本 | 🔴 | 混合脚本，功能强大 |
| 7 | .scr | 屏保程序 | 🔴 | 本质就是 exe，伪装成屏保 |
| 8 | .com | DOS命令 | 🔴 | 老格式，现在少见 |
| 9 | .pif | 程序信息 | 🔴 | 指向其他程序的快捷方式 |
| 10 | .msi | 安装包 | 🟠 | 安装包也可能带病毒 |

## 三、Office 宏文件危险吗？

### 3.1 什么是宏文件？

宏（Macro）是 Office 里的一种自动化功能，可以用 VBA 语言写脚本，自动完成重复性操作。

带宏的 Office 文件有特殊的后缀：

| 正常文件 | 带宏的文件 | 说明 |
|----------|-----------|------|
| .docx | .docm | Word 宏文档 |
| .xlsx | .xlsm | Excel 宏表格 |
| .pptx | .pptm | PowerPoint 宏演示 |

### 3.2 为什么危险？

宏可以执行 VBA 代码，而 VBA 能调用系统功能——也就是说，恶意宏能做病毒能做的任何事。

**典型攻击流程**：
1. 你收到一个邮件，附件是 `工资表.xlsm`
2. 你用 Excel 打开，顶部弹出"安全警告：宏已被禁用"
3. 邮件正文写着"请启用宏才能查看内容"
4. 你点了"启用内容"
5. 宏代码开始运行——病毒安装成功！

### 3.3 危险等级

| 后缀 | 危险等级 | 说明 |
|------|---------|------|
| .docm | 🟠 高危 | Word 宏文档，宏病毒常见载体 |
| .xlsm | 🟠 高危 | Excel 宏表格，宏病毒最常见 |
| .pptm | 🟡 中危 | PowerPoint 宏，相对少一些 |
| .doc | 🔴 极高危 | 旧版 Word 格式，宏和文档不分，默认可能启用宏 |
| .xls | 🔴 极高危 | 旧版 Excel 格式，同上 |

> **特别注意**：旧版的 .doc 和 .xls 文件（Office 97-2003 格式）是最危险的，因为它们把宏和正文存在一起，而且有些旧版软件默认会启用宏。

### 3.4 如何防护？

1. **默认禁用宏**：Office 默认就是禁用的，不要随便改
2. **不要随便点"启用内容"**：除非你确定这个文件是安全的
3. **旧版格式要警惕**：收到 .doc/.xls 文件要格外小心
4. **用最新版 Office**：新版本的安全机制更完善

## 四、脚本类危险后缀

除了上面提到的 .bat/.vbs/.js，还有很多脚本类后缀也需要注意：

| 后缀 | 名称 | 危险等级 | 说明 |
|------|------|---------|------|
| .ps1 | PowerShell 脚本 | 🔴 极高危 | PowerShell 功能极强，现在病毒很喜欢用 |
| .sh | Shell 脚本 | 🟠 高危 | Linux/Mac 脚本，Windows 上一般没事 |
| .py | Python 脚本 | 🟡 中危 | 需要装 Python 才能运行，一般人电脑上没有 |
| .rb | Ruby 脚本 | 🟡 中危 | 需要 Ruby 环境 |
| .pl | Perl 脚本 | 🟡 中危 | 需要 Perl 环境 |
| .php | PHP 脚本 | 🟡 中危 | 需要 PHP 环境，一般是网页用 |
| .ahk | AutoHotkey 脚本 | 🟠 高危 | 安装了 AHK 的话双击就运行，能模拟键盘鼠标 |
| .autoit | AutoIt 脚本 | 🟠 高危 | 类似 AHK，自动化脚本 |

**重点关注：.ps1 (PowerShell)**

PowerShell 是现在病毒和黑客的最爱，因为：
- Windows 7 以后系统自带，不用额外安装
- 功能极强，能调用几乎所有系统功能
- 可以从网上下载代码直接执行（无文件攻击）
- 很多企业环境里 PowerShell 默认是允许的

## 五、伪装技巧大揭秘

病毒作者为了让你双击文件，用尽了各种伪装手段。下面是最常见的几种：

### 5.1 双重后缀（最常见）

**原理**：利用 Windows 默认隐藏后缀的特性。

**示例**：
- 真实文件名：`美女图片.jpg.exe`
- 隐藏后缀后显示：`美女图片.jpg`
- 你以为是图片，双击后其实运行了 exe 病毒

**防范方法**：
- **一定要显示文件后缀！**（回去看基础原理那篇）
- 显示后你就能看到完整的 `.exe`，不会被骗

### 5.2 图标伪装

**原理**：给 exe 文件换一个文档/图片的图标。

**示例**：
- 病毒文件是 exe 格式
- 但它的图标是 PDF 图标、Word 图标、图片图标
- 你以为是文档，双击后运行了病毒

**防范方法**：
- 看后缀，不要只看图标
- 陌生文件先右键 → 属性，看看真实格式

### 5.3 文件名欺骗

**原理**：在文件名里做手脚。

**常见手法**：

| 手法 | 示例文件名 | 实际是什么 |
|------|-----------|-----------|
| 空格加后缀 | `报告 .exe` | 可执行文件 |
| 反向字符 | `报告fdp.exe`（用了RTLO字符，显示成`报告exe.pdf`） | 可执行文件 |
| 长得像的字母 | `报告.docx`（x是希腊字母χ，不是英文字母x） | 其实是别的后缀 |
| 超长文件名 | `非常重要的文件请务必查看.exe`（后面的.exe被挤到看不见） | 可执行文件 |

### 5.4 压缩包藏毒

**原理**：把病毒放在压缩包里，压缩包命名成正常文件。

**示例**：
- 压缩包名叫 `照片.zip`
- 你以为里面是照片，解压后发现是 `照片.exe`
- 或者更狠——压缩包里有个自解压格式，双击自动运行病毒

**防范方法**：
- 陌生压缩包先看看里面有什么再解压
- 不要运行压缩包里的 exe 文件，除非你确定来源可靠

### 5.5 快捷方式伪装

**原理**：用快捷方式（.lnk）指向病毒程序。

**示例**：
- 快捷方式名叫 `工作文档`
- 图标是 Word 图标
- 但它实际指向的是 `virus.exe`
- 你双击快捷方式，等于运行了病毒

**防范方法**：
- 右键快捷方式 → 属性 → 看"目标"指向哪里
- 陌生的快捷方式不要随便点

## 六、防护建议

### 6.1 必做的三件事

#### 1. 显示文件后缀名（最重要）

> ⚠️ **这是性价比最高的安全措施，没有之一！**

- Windows：文件夹 → 查看 → 勾选"文件扩展名"
- Mac：访达 → 设置 → 高级 → 显示所有文件扩展名

不显示后缀，你就是在"裸奔"——病毒用双重后缀一骗一个准。

#### 2. 安装杀毒软件

| 类型 | 推荐 | 说明 |
|------|------|------|
| 免费 | Windows Defender（系统自带） | Win10/11 自带的已经足够好了 |
| 免费 | 火绒安全 | 国产良心，干净无广告 |
| 付费 | 卡巴斯基、ESET NOD32 | 专业杀毒，防护更强 |

**不推荐**：某某卫士、某某管家（捆绑软件多、弹窗广告多）

#### 3. 不明来源的文件不要运行

- 陌生人发来的文件 → 不要运行
- 奇怪的邮件附件 → 不要运行
- 网站上弹窗"你的电脑有病毒，请下载修复工具" → 不要下载
- 群里转发的"福利""破解版" → 不要运行

### 6.2 进阶防护

| 措施 | 说明 |
|------|------|
| **从正规渠道下载软件** | 官网、微软应用商店，不要从第三方下载站下 |
| **开启 Windows SmartScreen** | 下载陌生程序时会警告 |
| **不关闭 UAC（用户账户控制）** | 程序要改系统设置时会弹提示 |
| **及时更新系统** | 修复安全漏洞 |
| **备份重要文件** | 万一中毒了还有备份 |
| **用沙箱运行可疑文件** | Windows 10/11 有沙箱功能 |

### 6.3 判断文件是否安全的 checklist

收到一个陌生文件，按以下顺序检查：

- [ ] **看后缀**：是不是高危后缀？（.exe、.bat、.vbs 等）
- [ ] **看来源**：是谁发给你的？认识吗？可靠吗？
- [ ] **看大小**：说是图片但只有几 KB？可能是病毒
- [ ] **看图标**：图标和后缀对得上吗？
- [ ] **杀毒软件扫一下**：右键 → 扫描病毒
- [ ] **不确定就别运行**：宁可不看，也不要中毒

## 七、⚠️ 红色警告区块

> 🔴🔴🔴 **请务必牢记以下内容** 🔴🔴🔴

### 绝对不能双击的情况

1. **陌生人发来的 .exe 文件** —— 不管说得多好听，都不要点
2. **邮件附件里的 .docm/.xlsm 文件** —— 尤其是让你"启用宏"的
3. **名字看起来像图片但后缀是 .exe/.scr 的** —— 100% 是病毒
4. **群里转发的"福利""破解工具""刷钻软件"** —— 基本都是病毒
5. **浏览器提示"你的电脑有病毒，请立即下载清理工具"** —— 那弹窗本身就是病毒

### 中毒了怎么办？

1. **立即断开网络** —— 防止病毒继续传播或上传你的数据
2. **不要重启电脑** —— 有些病毒重启后会更难清除
3. **用杀毒软件全盘扫描** —— 如果还能运行的话
4. **重要文件备份** —— 用U盘拷出来，但要先确认文件没被感染
5. **实在不行就重装系统** —— 这是最彻底的解决方法
6. **如果是勒索病毒** —— 不要付钱（付了也不一定能解密），找专业数据恢复公司

### 一句话安全守则

> **不确定的文件，就不要运行。**
>
> 哪怕错过一个"福利"，也比电脑中毒、数据丢失、账号被盗强一万倍。

## 💡 小结

1. **高危后缀**就是能直接执行代码的文件，双击就能让病毒在你电脑上为所欲为
2. **TOP10 高危后缀**：exe、bat、cmd、vbs、js、wsf、scr、com、pif、msi
3. **Office 宏文件**（.docm、.xlsm、.pptm）也很危险，不要随便启用宏
4. **最常见的伪装**：双重后缀（`.jpg.exe`）、图标伪装、文件名欺骗
5. **防护三件套**：显示后缀名 + 杀毒软件 + 不运行不明文件
6. **安全第一原则**：不确定的文件，就不要运行
