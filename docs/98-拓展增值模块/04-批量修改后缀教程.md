# 04 - 批量修改后缀教程

> 有 100 个文件要改后缀？一个一个改太麻烦了！本文教你用命令行和工具一键批量修改。

---

## 一、什么时候需要批量改后缀？

以下是常见的批量修改后缀的场景：

- 把一堆 `.txt` 文件改成 `.md`（Markdown 格式）
- 把 `.jpeg` 统一改成 `.jpg`
- 把图片从 `.png` 转成 `.jpg` 后的重命名
- 下载的文件后缀被搞错了，需要批量改回来
- 批量给文件加后缀或去后缀

> ⚠️ **再次提醒**：改后缀 ≠ 转换格式！如果需要真正的格式转换，请看下一篇《文件格式转换通用方案》。

---

## 二、安全提醒（必读）

> 🔴 **批量操作有风险，操作前请务必注意以下事项**

### 2.1 先备份

批量重命名操作是不可逆的（除非你马上按 Ctrl+Z）。操作前最好：

1. **复制一份**整个文件夹作为备份
2. 或者先**压缩打包**一份
3. 重要文件务必先备份，再操作

### 2.2 先测试一个

不要一上来就对几百个文件操作：

1. 先**挑一个文件**测试命令/方法
2. 确认效果符合预期
3. 再批量操作全部文件

### 2.3 在测试文件夹里练手

第一次使用某个方法时：

1. 创建一个空文件夹
2. 复制几个测试文件进去
3. 用测试文件练习
4. 熟练了再去操作真实文件

### 2.4 确认范围

执行批量命令前，确认：

- 你在正确的目录下吗？
- 命令会影响哪些文件？
- 会不会误改到子文件夹里的文件？
- 文件名中有没有特殊字符（空格、中文等）？

## 三、Windows 方法

### 3.1 方法一：CMD ren 命令（最简单）

#### 基本语法

```cmd
ren 旧文件匹配 新文件匹配
```

`ren` 是 `rename` 的缩写，两个都能用。

#### 示例

**示例 1：把所有 .txt 改成 .md**

```cmd
ren *.txt *.md
```

**示例 2：把所有 .jpeg 改成 .jpg**

```cmd
ren *.jpeg *.jpg
```

**示例 3：把所有 .htm 改成 .html**

```cmd
ren *.htm *.html
```

#### 操作步骤

1. 打开目标文件夹
2. 在地址栏输入 `cmd`，按回车（会打开当前目录的 CMD 窗口）
3. 输入上面的命令，按回车
4. 完成！

#### 注意事项

- `*` 是通配符，代表"任意字符"
- `ren *.txt *.md` 的意思是：所有后缀为 .txt 的文件，把后缀改成 .md
- 只会改当前目录的文件，不会影响子文件夹
- 文件名中有空格也没问题，CMD 的 ren 命令能处理

#### 局限性

- 只能改后缀，不能改文件名的其他部分
- 不能递归处理子文件夹
- 功能比较基础

### 3.2 方法二：PowerShell（功能更强）

PowerShell 比 CMD 强大得多，可以写更复杂的逻辑。

#### 基本语法

```powershell
Get-ChildItem -Filter "*.旧后缀" | Rename-Item -NewName { $_.Name -replace '\.旧后缀$','.新后缀' }
```

也可以用简写：

```powershell
dir *.旧后缀 | ren -NewName { $_.Name -replace '\.旧后缀$','.新后缀' }
```

#### 示例

**示例 1：把所有 .txt 改成 .md**

```powershell
Get-ChildItem -Filter "*.txt" | Rename-Item -NewName { $_.Name -replace '\.txt$', '.md' }
```

**示例 2：递归处理子文件夹**

```powershell
Get-ChildItem -Filter "*.txt" -Recurse | Rename-Item -NewName { $_.Name -replace '\.txt$', '.md' }
```

加上 `-Recurse` 参数就会递归处理所有子文件夹。

**示例 3：只改文件名包含特定文字的文件**

```powershell
# 只把文件名包含"报告"的 .txt 改成 .md
Get-ChildItem -Filter "*报告*.txt" | Rename-Item -NewName { $_.Name -replace '\.txt$', '.md' }
```

**示例 4：批量去掉后缀**

```powershell
# 把所有 .bak 文件的 .bak 后缀去掉（file.txt.bak → file.txt）
Get-ChildItem -Filter "*.bak" | Rename-Item -NewName { $_.Name -replace '\.bak$', '' }
```

**示例 5：批量添加后缀**

```powershell
# 给所有没有后缀的文件加上 .txt
Get-ChildItem -File | Where-Object { $_.Extension -eq '' } | Rename-Item -NewName { $_.Name + '.txt' }
```

#### 操作步骤

1. 打开目标文件夹
2. 在地址栏输入 `powershell`，按回车
3. 输入命令，按回车
4. 完成

#### 小技巧：先预览再执行

不确定效果？加个 `-WhatIf` 参数先预览：

```powershell
Get-ChildItem -Filter "*.txt" | Rename-Item -NewName { $_.Name -replace '\.txt$', '.md' } -WhatIf
```

这样只会显示会改哪些文件，不会真的执行。确认没问题后，去掉 `-WhatIf` 再运行。

### 3.3 方法三：资源管理器批量重命名（图形界面）

如果你不想用命令行，Windows 资源管理器也有批量重命名功能：

1. 选中所有要改后缀的文件（Ctrl+A 全选，或按住 Ctrl 点选）
2. 按 F2（或右键 → 重命名）
3. 输入新的名字（比如 `图片.jpg`）
4. 按回车
5. 所有文件会变成 `图片 (1).jpg`、`图片 (2).jpg`……

**缺点**：这个方法会把文件名也改了，而且是按序号命名的，不是只改后缀。适合不在乎文件名的场景。

## 四、Mac / Linux 方法

### 4.1 方法一：mv 命令（最基础）

#### 基本思路

用 `mv` 命令配合循环来批量修改：

```bash
for f in *.旧后缀; do
    mv "$f" "${f%.旧后缀}.新后缀"
done
```

`${f%.旧后缀}` 的意思是去掉文件名末尾的 `.旧后缀`。

#### 示例

**示例 1：把所有 .txt 改成 .md**

```bash
for f in *.txt; do
    mv "$f" "${f%.txt}.md"
done
```

也可以写成一行：

```bash
for f in *.txt; do mv "$f" "${f%.txt}.md"; done
```

**示例 2：递归处理子文件夹**

```bash
find . -name "*.txt" -exec bash -c 'mv "$0" "${0%.txt}.md"' {} \;
```

或者用 `find` + `while`：

```bash
find . -name "*.txt" | while read f; do
    mv "$f" "${f%.txt}.md"
done
```

**示例 3：批量去掉后缀**

```bash
# 把 .bak 后缀去掉（file.txt.bak → file.txt）
for f in *.bak; do
    mv "$f" "${f%.bak}"
done
```

**示例 4：批量添加后缀**

```bash
# 给所有没有后缀的文件加上 .txt
for f in *; do
    [[ -f "$f" && "$f" != *.* ]] && mv "$f" "${f}.txt"
done
```

#### 注意事项

- 一定要给变量加引号（`"$f"`），否则文件名有空格会出错
- `${f%.txt}` 这种写法是 Bash 的参数扩展，其他 Shell 可能不支持
- `mv` 命令不会有确认提示，操作要小心

### 4.2 方法二：rename 命令（更方便）

`rename` 命令可以用正则表达式批量重命名，比写 for 循环更简洁。

#### 注意：有两个版本的 rename

Linux 上有两种 `rename` 命令，语法不一样：

| 版本 | 语法 | 常见发行版 |
|------|------|-----------|
| Perl 版 | `rename 's/旧/新/' 文件` | Ubuntu、Debian |
| util-linux 版 | `rename 旧 新 文件` | CentOS、RedHat |

怎么判断你的是哪个版本？输入 `man rename` 看看说明。

#### Perl 版 rename（Ubuntu/Debian）

**示例 1：把 .txt 改成 .md**

```bash
rename 's/\.txt$/.md/' *.txt
```

**示例 2：递归改所有子文件夹**

```bash
find . -name "*.txt" -exec rename 's/\.txt$/.md/' {} +
```

**示例 3：把文件名转成小写**

```bash
rename 'y/A-Z/a-z/' *
```

**示例 4：去掉文件名中的空格**

```bash
rename 's/ /_/g' *
```

#### util-linux 版 rename（CentOS/RedHat）

**示例 1：把 .txt 改成 .md**

```bash
rename .txt .md *.txt
```

**示例 2：把文件名中的"照片"改成"图片"**

```bash
rename 照片 图片 *.jpg
```

#### Mac 上安装 rename

Mac 默认没有 `rename` 命令，可以用 Homebrew 安装：

```bash
brew install rename
```

安装后就是 Perl 版本的 rename。

## 五、批量修改示例汇总

### 5.1 常见场景速查

| 场景 | Windows CMD | PowerShell | Mac/Linux |
|------|------------|-----------|-----------|
| txt → md | `ren *.txt *.md` | `dir *.txt \| ren -NewName {$_.Name -replace '\.txt$','.md'}` | `for f in *.txt; do mv "$f" "${f%.txt}.md"; done` |
| jpeg → jpg | `ren *.jpeg *.jpg` | `dir *.jpeg \| ren -NewName {$_.Name -replace '\.jpeg$','.jpg'}` | `rename 's/\.jpeg$/.jpg/' *.jpeg` |
| png → jpg | `ren *.png *.jpg` | `dir *.png \| ren -NewName {$_.Name -replace '\.png$','.jpg'}` | `for f in *.png; do mv "$f" "${f%.png}.jpg"; done` |
| htm → html | `ren *.htm *.html` | `dir *.htm \| ren -NewName {$_.Name -replace '\.htm$','.html'}` | `rename 's/\.htm$/.html/' *.htm` |
| 去后缀 .bak | 不支持 | `dir *.bak \| ren -NewName {$_.Name -replace '\.bak$',''}` | `for f in *.bak; do mv "$f" "${f%.bak}"; done` |
| 递归子目录 | 不支持 | `dir *.txt -Recurse \| ren -NewName {$_.Name -replace '\.txt$','.md'}` | `find . -name "*.txt" -exec rename 's/\.txt$/.md/' {} +` |

> ⚠️ **再次强调**：上面这些只是改文件名后缀，文件的实际内容并没有变。如果需要真正的格式转换（比如 PNG 真的转成 JPG），请用格式转换工具。

### 5.2 一个完整的实战案例

**需求**：一个文件夹里有 500 张图片，后缀既有 `.jpg` 又有 `.jpeg`，想统一成 `.jpg`。

**操作步骤（Windows PowerShell）**：

1. 打开图片文件夹
2. 地址栏输入 `powershell`，回车
3. 先预览一下有多少个 .jpeg 文件：

```powershell
(Get-ChildItem -Filter "*.jpeg").Count
```

4. 先拿一个文件测试：

```powershell
# 找一个文件测试
Get-ChildItem -Filter "*.jpeg" | Select-Object -First 1 | Rename-Item -NewName { $_.Name -replace '\.jpeg$', '.jpg' } -WhatIf
```

5. 确认没问题，执行批量修改：

```powershell
Get-ChildItem -Filter "*.jpeg" | Rename-Item -NewName { $_.Name -replace '\.jpeg$', '.jpg' }
```

6. 验证结果：

```powershell
# 看看还有没有 .jpeg 文件
(Get-ChildItem -Filter "*.jpeg").Count

# 看看 .jpg 文件数量增加了多少
(Get-ChildItem -Filter "*.jpg").Count
```

7. 完成！

## 六、常见问题 FAQ

### Q1：批量改后缀后文件打不开了？
大概率是你把后缀改错了。改回去试试。如果记不清原来的后缀了，用 [未知后缀查询指南](./01-未知后缀查询指南.md) 里的方法看看文件头。

### Q2：文件名有空格，命令报错怎么办？
- CMD 的 ren 命令一般没问题
- PowerShell 和 Bash 里要给变量加引号（`"$f"`）
- 或者用图形界面工具，完全不用考虑这个问题

### Q3：改完后悔了，能撤销吗？
- 刚改完的话，在资源管理器里按 Ctrl+Z 可能可以撤销
- 命令行操作的话……不能撤销，只能手动改回去
- 所以操作前备份很重要！

### Q4：怎么批量修改文件名（不只是后缀）？
- 简单修改：PowerShell 或 rename 命令的正则表达式
- 复杂需求：用专门的批量重命名软件（ReNamer、Advanced Renamer 等）

### Q5：子文件夹里的文件也想改怎么办？
- PowerShell 加 `-Recurse` 参数
- Mac/Linux 用 `find` 命令配合
- 图形界面软件一般都有递归选项

---

## 💡 小结

1. **Windows 用户**：简单的用 CMD 的 `ren`，复杂的用 PowerShell，再不行就用软件
2. **Mac/Linux 用户**：简单的用 `mv` 循环，方便的用 `rename` 命令
3. **安全第一**：先备份、先测试一个、先预览效果
4. **改后缀 ≠ 转格式**：只是改名字，文件内容不变
5. **大量复杂操作**：用专业的批量重命名软件，效率高、不容易出错
