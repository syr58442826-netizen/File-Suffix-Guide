# 05 - 文件格式转换通用方案

> 需要把 PDF 转 Word？PNG 转 JPG？MP4 转 MP3？本文整理了各类格式转换的方案和工具推荐，帮你找到最合适的转换方式。

---

## 一、格式转换的基本概念

### 1.1 什么是格式转换？

格式转换就是把文件从一种编码格式变成另一种，让不同的软件/设备能够读取。

和"改后缀"不同——格式转换是**真的改变文件内部的数据结构**，而不是只改个名字。

### 1.2 有损转换 vs 无损转换

| 类型 | 说明 | 质量变化 | 常见场景 |
|------|------|---------|---------|
| **无损转换** | 转换后质量完全不变 | 无损失 | PNG ↔ BMP、WAV ↔ FLAC |
| **有损转换** | 转换时会丢弃一些数据 | 质量下降 | PNG → JPG、WAV → MP3 |

**重要原则**：
- 有损格式转有损格式 → 质量会越来越差（二次损失）
- 尽量从无损/高质量源文件转换
- 不要反复转换同一个文件

### 1.3 能不能转的判断

不是所有格式之间都能互相转换：

| 情况 | 能转吗 | 示例 |
|------|--------|------|
| 同类格式之间 | ✅ 能 | JPG ↔ PNG、MP3 ↔ WAV |
| 文档转文档 | ⚠️ 部分能 | Word ↔ PDF（PDF 转 Word 可能排版错乱） |
| 图片转文档 | ⚠️ 需要 OCR | 图片中的文字 → Word（需要文字识别） |
| 视频转音频 | ✅ 能 | MP4 → MP3（提取音频） |
| 音频转视频 | ❌ 不能 | 只有声音没有画面 |
| 文本转图片 | ✅ 能 | 但本质是截图，文字不可复制 |

## 二、文档格式转换

### 2.1 PDF 相关转换

#### PDF → Word / Excel / PPT

**场景**：拿到一个 PDF，想编辑里面的内容。

| 工具 | 类型 | 优点 | 缺点 | 推荐指数 |
|------|------|------|------|---------|
| **Adobe Acrobat Pro** | 本地软件 | 转换质量最好，排版保留好 | 收费贵 | ⭐⭐⭐⭐⭐ |
| **WPS Office** | 本地软件 | 中文支持好，会员功能全 | 高级功能需会员 | ⭐⭐⭐⭐ |
| **Smallpdf** | 在线工具 | 界面简洁，转换质量不错 | 免费版有次数限制 | ⭐⭐⭐⭐ |
| **iLovePDF** | 在线工具 | 功能多，PDF 工具全家桶 | 免费版有广告和水印 | ⭐⭐⭐⭐ |
| **PDF24 Tools** | 在线/本地 | 完全免费，功能多 | 界面一般 | ⭐⭐⭐⭐ |
| **ABBYY FineReader** | 本地软件 | OCR 最强，扫描件也能转 | 价格高 | ⭐⭐⭐⭐ |
| **百度网盘 / 腾讯文档** | 在线服务 | 国内访问快 | 质量一般 | ⭐⭐⭐ |

**注意**：
- PDF 转 Word 后，**排版大概率会错乱**，需要手动调整
- 如果 PDF 是扫描件（图片），需要 OCR 文字识别才能转成可编辑的 Word
- 复杂排版的 PDF（如杂志、海报）很难完美转换

#### Word / Excel / PPT → PDF

**场景**：做好的文档要发给别人，确保格式不变。

| 工具 | 方法 |
|------|------|
| **Microsoft Office** | 文件 → 另存为 → 选择 PDF |
| **WPS Office** | 文件 → 输出为 PDF |
| **Windows 10/11** | 打印 → 选择"Microsoft Print to PDF" |
| **Mac** | 文件 → 打印 → 左下角"PDF"按钮 → 存储为 PDF |
| **LibreOffice** | 文件 → 导出为 PDF |

**推荐**：用 Office/WPS 直接"另存为"PDF 质量最好，比打印成 PDF 更清晰。

#### PDF ↔ 图片

**PDF → 图片**：
- Adobe Acrobat：导出 PDF → 图像 → JPEG/PNG
- 在线工具：Smallpdf、iLovePDF 都有 PDF 转图片功能
- 最简单：直接截图（质量取决于截图分辨率）

**图片 → PDF**：
- Windows：选中图片 → 右键 → 打印 → 选择"Microsoft Print to PDF"
- Mac：预览打开 → 文件 → 导出为 PDF
- 在线工具：iLovePDF、Smallpdf

### 2.2 Office 格式之间转换

#### Word ↔ Excel

- 简单表格：直接复制粘贴
- 复杂格式：用 Word 的"插入表格"或 Excel 的"复制为图片"
- 注意：这俩格式差异很大，没有完美转换的方法

#### PPT → Word / PDF

- PPT → Word：文件 → 导出 → 创建讲义（把备注和幻灯片导出到 Word）
- PPT → PDF：直接另存为 PDF，效果很好

#### 旧格式 → 新格式（.doc → .docx）

- 用 Word 打开 .doc 文件 → 另存为 → 选择 .docx
- 批量转换：可以用 Word 宏或专门的转换工具

### 3.3 常见转换场景

| 转换方向 | 推荐工具 | 注意事项 |
|----------|---------|---------|
| PNG → JPG | 画图/预览/在线工具 | 会丢失透明背景，体积变小 |
| JPG → PNG | 任何工具 | 体积会变大，质量不会提升 |
| HEIC → JPG | 在线转换/iPhone 导出时选 JPG | iPhone 拍的照片默认 HEIC |
| WebP → JPG/PNG | 在线转换/XnConvert | WebP 兼容性越来越好了 |
| BMP → JPG/PNG | 任何工具 | BMP 体积太大，建议转成 JPG/PNG |
| GIF → MP4 | FFmpeg/在线工具 | 视频格式体积更小，更适合网页 |
| 批量转换 | XnConvert / ImageMagick / 在线批量工具 | 大量图片建议用本地工具 |

### 3.4 ImageMagick 命令行示例（程序员推荐）

```bash
# 单张转换 PNG → JPG
convert input.png output.jpg

# 批量转换（所有 PNG 转 JPG）
mogrify -format jpg *.png

# 转换并调整质量（85%）
convert input.png -quality 85 output.jpg

# 调整大小（宽 800px，高度按比例）
convert input.jpg -resize 800 output.jpg

# 批量压缩（质量 80%，最大宽度 1920）
mogrify -quality 80 -resize 1920x1920\> *.jpg
```

| 转换方向 | 推荐工具 | 说明 |
|----------|---------|------|
| 各种格式 → MP4 | HandBrake / FFmpeg | MP4 兼容性最好，通用 |

#### FFmpeg 常用命令（进阶）

```bash
# 格式转换（MP4 → MKV）
ffmpeg -i input.mp4 output.mkv

# 视频压缩（H.264，质量 23）
ffmpeg -i input.mp4 -c:v libx264 -crf 23 output.mp4

# 提取音频（MP4 → MP3）
ffmpeg -i input.mp4 -vn -acodec libmp3lame -q:a 2 output.mp3

# 批量转换（当前目录所有 AVI 转 MP4）
for f in *.avi; do ffmpeg -i "$f" -c:v libx264 -crf 23 "${f%.avi}.mp4"; done

# 调整分辨率（1920x1080）
ffmpeg -i input.mp4 -s 1920x1080 output.mp4

# GIF 转 MP4
ffmpeg -i input.gif -movflags faststart -pix_fmt yuv420p -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" output.mp4
```

## 七、转换质量与文件大小的权衡

### 7.1 影响文件大小的因素

| 格式类型 | 主要影响因素 |
|----------|-------------|
| 图片 | 分辨率、格式、压缩质量、颜色数量 |
| 视频 | 分辨率、码率、帧率、编码格式、时长 |
| 音频 | 采样率、比特率、声道数、编码格式 |
| 文档 | 内容多少、是否含图片、压缩方式 |

### 7.2 常见格式的体积对比（同等质量）

**图片**（以一张 1920x1080 照片为例）：

| 格式 | 大约体积 | 说明 |
|------|---------|------|
| BMP | ~6MB | 最大，无损不压缩 |
| PNG | ~3MB | 无损压缩，体积中等 |
| JPG（高质量 90%） | ~800KB | 有损，肉眼看不出区别 |
| JPG（中等质量 60%） | ~300KB | 有损，仔细看有区别 |
| WebP（高质量） | ~500KB | 比 JPG 更小，质量相当 |

**视频**（以 1080p 1 分钟为例）：

| 格式/码率 | 大约体积 | 说明 |
|----------|---------|------|
| 无压缩 | ~3GB | 原始素材，巨大 |
| AVI（MPEG2） | ~500MB | 老格式，体积大 |
| MP4（H.264，高码率） | ~100MB | 高质量，体积合理 |
| MP4（H.264，中码率） | ~50MB | 网络视频常用 |
| MP4（H.265，同质量） | ~50MB | 比 H.264 小一半 |

**音频**（以 3 分钟歌曲为例）：

| 格式/比特率 | 大约体积 | 说明 |
|------------|---------|------|
| WAV（无损） | ~30MB | CD 音质，体积大 |
| FLAC（无损） | ~15MB | 无损压缩，体积减半 |
| MP3（320kbps） | ~7MB | 高音质，接近无损 |
| MP3（192kbps） | ~4MB | 不错的音质，大多数人听不出区别 |
| MP3（128kbps） | ~3MB | 一般音质，体积小 |

### 7.3 权衡建议

| 场景 | 建议 |
|------|------|
| **原图/原始素材** | 保存无损格式（PNG、WAV、RAW），留作底版 |
| **网页/分享用** | 用有损压缩，找到"体积小 + 看不出区别"的平衡点 |
| **打印/出版** | 用高质量/无损格式，确保清晰度 |
| **手机存储** | 用高压缩比格式，节省空间 |
| **归档备份** | 用无损格式，保留最高质量 |

### 7.4 一个实用的"三步法"

1. **第一步：确定目标用途**
   - 是网上分享？还是打印？还是存档？

2. **第二步：选择合适的格式和参数**
   - 网上分享 → JPG（85% 质量）/ MP4（H.264）/ MP3（192kbps）
   - 打印存档 → PNG/TIFF / WAV / 原始格式

3. **第三步：转换后检查质量**
   - 打开看看，效果能接受吗？
   - 体积合适吗？
   - 不满意就调参数再转一次

## 八、常见问题 FAQ

### Q1：转换后的文件打不开怎么办？
- 检查转换过程是否出错了（有没有报错信息）
- 换个软件试试能不能打开
- 源文件本身是不是坏的
- 是不是转换时参数设错了

### Q2：PDF 转 Word 后排版全乱了？
这是正常现象。PDF 是版式固定的格式，Word 是流式排版，转换时很难 100% 还原。
- 简单文档：基本能转换好
- 复杂排版（多栏、图片、表格）：需要手动调整
- 扫描件 PDF：需要 OCR，排版更是没法保证

### Q3：视频转换后画质变差了？
- 提高码率/质量参数
- 用更好的编码器（H.264 比 MPEG4 好，H.265 比 H.264 好）
- 如果源文件质量就不好，再怎么转也不会变好（垃圾进，垃圾出）

### Q4：图片转了格式反而变大了？
比如 JPG 转 PNG，体积可能变大 2-3 倍。因为 PNG 是无损的，它会保留所有细节——包括 JPG 压缩产生的噪点。
- 如果源文件是 JPG，就没必要转成 PNG（质量不会提升，体积还变大）
- 只有源文件是无损格式时，转成 PNG 才有意义

### Q5：批量转换用什么工具好？
- 图片：XnConvert（图形界面）、ImageMagick（命令行）
- 视频：FFmpeg（命令行）、HandBrake（图形界面+队列）
- 音频：FFmpeg、XLD（Mac）
- 文档：WPS 批量转换、专门的工具软件

---

## 💡 小结

1. **格式转换 ≠ 改后缀**：转换是真的改变数据结构，改后缀只是换名字
2. **文档转换**：PDF 转其他格式质量有限制，复杂排版需要手动调整
3. **图片转换**：优先用 XnConvert / ImageMagick，在线工具适合小文件
4. **视频转换**：HandBrake（图形）和 FFmpeg（命令行）是两大神器
5. **在线工具**：方便但有隐私风险，敏感文件不要上传
6. **质量 vs 体积**：根据用途选择合适的格式和参数，追求最佳平衡
7. **无损源文件很重要**：始终保留一份原始高质量文件作为底版
