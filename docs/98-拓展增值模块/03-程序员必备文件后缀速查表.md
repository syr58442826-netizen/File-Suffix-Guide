## 五、配置文件速查

### 5.1 结构化配置

| 后缀 | 格式 | 特点 | 常见用途 |
|------|------|------|---------|
| .json | JSON | 严格、无注释、跨语言 | 前端配置、API 数据 |
| .yaml / .yml | YAML | 易读、支持注释、缩进敏感 | K8s、CI/CD、Ansible |
| .xml | XML | 严格、层级清晰、冗长 | Java、Android、旧系统 |
| .toml | TOML | 易读、键值对、类似 INI | Rust、Python、Go 项目 |
| .ini / .cfg | INI | 简单、节+键值对 | Windows、Python、Git |
| .properties | Properties | Java 风格键值对 | Java 生态 |
| .conf | 通用配置 | 格式多样，看具体软件 | Nginx、MySQL 等 |

### 5.2 点文件（Dotfiles）

这些文件以点开头，通常是隐藏的配置文件：

| 文件名 | 用途 |
|--------|------|
| `.gitignore` | Git 忽略文件配置 |
| `.gitconfig` | Git 全局配置 |
| `.bashrc` / `.bash_profile` | Bash Shell 配置 |
| `.zshrc` | Zsh Shell 配置 |
| `.vimrc` | Vim 编辑器配置 |
| `.env` | 环境变量配置 |
| `.editorconfig` | 编辑器统一配置 |
| `.npmrc` | npm 配置 |
| `.prettierrc` | Prettier 格式化配置 |
| `.eslintrc` | ESLint 代码检查配置 |

## 💡 小结

1. **前端三件套**：HTML + CSS + JavaScript，框架层有 Vue、React、Angular
2. **后端语言各有生态**：Java（.java/.jar/.class）、Python（.py/.pyc）、Go（.go）、Rust（.rs）等
3. **配置文件格式多样**：JSON、YAML、TOML、XML、INI 各有适用场景
4. **锁文件很重要**：每个包管理器都有自己的锁文件，确保依赖版本一致
5. **命名约定很关键**：很多后缀是约定俗成的（如 `*_test.go`、`*.test.js`），不是强制的但大家都遵守
6. **本文是速查表**：详细说明请参考对应分类的独立文档
