## 为什么叫"拓展增值模块"？

基础模块（01-08）是按文件类型分类的，每个后缀一篇详细文档。而本模块的内容不针对某一种特定格式，而是**通用的技巧、工具和知识**，能帮你解决各种文件相关的"疑难杂症"。
