# File-Suffix-Guide 在线查询工具

一个纯前端的文件后缀在线查询工具，无需服务器，双击即可使用。

## 快速开始

### 最简单的使用方式

直接双击 `index.html` 文件，用浏览器打开即可使用。

> **推荐浏览器**：Firefox、Edge、Chrome（最新版本）

### 如果遇到数据加载失败

部分浏览器（如 Chrome）出于安全考虑，默认不允许本地页面读取本地 JSON 文件。如果遇到此问题，可以尝试以下解决方案：

1. **使用 Firefox 浏览器** — Firefox 对本地文件限制较宽松，直接双击即可正常使用
2. **使用 VS Code + Live Server 插件** — 在 VS Code 中打开项目目录，右键 `index.html` 选择 "Open with Live Server"
3. **使用 Python 启动本地服务器**：
   ```bash
   # 在 web 目录下执行
   python -m http.server 8000
   # 然后在浏览器访问 http://localhost:8000
   ```
4. **使用 Node.js 启动**：
   ```bash
   npx serve .
   ```

## 功能介绍

### 🔍 实时搜索
- 在搜索框中输入关键词，实时筛选匹配结果
- 支持搜索后缀名、中文名、分类和标签
- 快捷键：`Ctrl + K` 快速聚焦搜索框
- 支持模糊匹配，输入部分文字即可

### 📂 分类筛选
- 15 个文件分类按钮，点击即可筛选对应分类的后缀
- 点击"全部"按钮重置筛选
- 分类涵盖：日常办公、图片设计、音视频、压缩包、可执行程序、编程源码、数据配置、字体系统、3D建模、移动应用、小众文档、小众媒体、高级编程、虚拟化数据库、邮件日历等

### 🔤 字母索引
- 顶部 A-Z 字母导航条
- 点击字母快速跳转到对应首字母的后缀
- 数字开头的后缀归入 `#` 分类
- 没有对应后缀的字母显示为灰色（不可点击）
- 再次点击已选中字母可取消筛选

### 📇 卡片展示
- 每个后缀以卡片形式展示
- 显示后缀名、中文名称、所属分类、标签
- 点击卡片查看详细信息弹窗
- 弹窗中提供"查看完整文档"链接，跳转到对应 Markdown 文档

### 🌙 暗色 / 亮色主题
- 右上角主题切换按钮
- 自动检测系统主题偏好
- 主题设置保存到本地存储，下次打开自动恢复

### 📱 响应式设计
- 完美适配桌面端、平板和手机
- 手机端卡片自适应两列布局
- 触控友好的交互设计

## 数据更新

`data.json` 文件包含所有后缀数据。如果项目文档有更新，可以重新生成数据：

```bash
# 运行项目根目录下的数据生成脚本
python generate_data.py
```

数据结构说明：
```json
[
  {
    "suffix": "txt",           // 后缀名
    "name": "纯文本文件",       // 中文名/描述
    "category": "日常办公文档类", // 分类名称
    "categoryPath": "01-日常办公文档类", // 分类路径
    "docPath": "docs/01-日常办公文档类/txt.md", // 文档相对路径
    "tags": ["文本", "办公", "通用"] // 标签数组
  }
]
```

## 技术特点

- **纯前端实现** — 无需后端服务器，零依赖
- **零框架** — 原生 HTML / CSS / JavaScript，无需构建
- **体积小** — 所有文件加起来不到 100KB（不含数据）
- **加载快** — 本地打开秒级响应
- **可离线** — 完全离线可用
- **可定制** — 代码结构清晰，易于修改和扩展
