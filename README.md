# File-Suffix-Guide
本项目整理各类常见文件后缀，覆盖文档、图片、音频、视频、代码、压缩包、可执行文件等类型。说明每种后缀对应的文件格式、用途、典型打开软件，帮助快速识别文件类型。This project introduces various file extensions, including document, image, audio, video, code, compressed and executable formats. It explains each file format’s purpose and recommended opening software, to help users identify file types.
