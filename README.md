## 📖 项目介绍

**File-Suffix-Guide** 是一个面向所有人的文件后缀百科全书。无论是电脑新手还是资深工程师，都能在这里找到你需要的文件格式使用指南。

每一类文件都包含：
- ✅ **后缀含义** — 文件是什么、用来干嘛
- ✅ **打开软件** — 免费 / 专业软件推荐
- ✅ **运行方法** — 双击、命令行、编译环境
- ✅ **编辑方式** — 如何修改和导出
- ✅ **安全风险** — 哪些后缀需要警惕
- ✅ **跨平台适配** — Windows / Mac / Linux 差异

## 🚀 快速入门：先显示文件后缀

> ⚠️ **新手必看**：Windows 默认隐藏后缀名，不显示的话根本不知道文件类型！

**Windows 10/11 显示后缀方法：**
1. 打开任意文件夹
2. 顶部菜单栏 → 「查看」→ 勾选「文件扩展名」

**详细图文教程 →** [文件后缀基础原理](docs/99-通用前置知识/01-文件后缀基础原理.md)
